# 大猫猫 · 原版像素版

本次版本按 2026-09-25 的修正要求重做材质：不是毛发质感，而是将放大后的原版色块细分为更小的像素。

## 打开文件

- `giant_tabby_boss.bbmodel`：Blockbench 可编辑源文件，内嵌贴图。
- `giant_tabby_boss.png`：256×256 像素图集。
- `giant_tabby_boss.glb`：带贴图、骨骼和动画的通用模型文件。
- `giant_tabby_boss.geo.json`、`giant_tabby_boss.animation.json`：Blockbench 原生导出的几何和动画，接入游戏时仍需配套实体及渲染代码。
- `previews/`：模型的实际渲染图，不是概念图。
- `source/`：用户提供的原版猫模型和贴图；不包含被弃用的毛发材质。

## 像素规格

模型已按原版猫的尺寸等比例放大 4 倍。保留猫的轮廓、原版橘色条纹、绿色眼睛和白色爪尖，增加一块前胸腹模型、稍突出的鼻口部和细红项圈。

16 模型单位 = 1 个 Minecraft 方块。每个模型单位对应 1 个贴图像素，因此任意 1×1 格的平面对应 16×16 个像素。78 个面的 UV 单独按实际尺寸排列；256×256 是整张图集的尺寸，不是一个方块的纹理尺寸。

原版的大色块中只增加少量低对比的 1～2 像素阶梯状色块，不添加毛丝、笔刷纹理、渐变或半透明边缘。全图使用 60 种不透明颜色，采样使用 Nearest（最近邻）。保持当前模型尺寸时，一个像素为 1/16 格。若在游戏渲染器中再放大 N 倍，密度会降为 16/N，需同步重新制作 UV 和贴图；不要再次直接放大模型。

## 验证

- 在 Blockbench 5.2.0 导入：13 个立方体、9 根骨骼、8 段动画，贴图加载无错误。
- 所有 78 个面的横、纵贴图密度均为 16 像素/格；检查 1950 个 UV 内部样点，均不透明。
- 8 段动画以 120 帧/秒抽样检查地面穿透，共 1676 个时刻，最低顶点不低于地面。此项不是游戏内战斗测试。
- GLB 内嵌像素贴图，放大和缩小过滤均为最近邻；保留 8 段动画。
- ZIP 打包后重新读取并逐文件校验 SHA-256。

这是独立模型素材包，本次没有注册新的 Boss、修改现有 Boss，也没有修改或部署模组 JAR。

## 仓库内重建

按顺序运行 `node tools/rebuild-giant-tabby-v2.mjs`、原生 Blockbench 导出脚本 `node tools/giant-tabby-native-v2.mjs export`、`node tests/giant-tabby-v2.mjs`、`node tools/package-giant-tabby-pixel16.mjs`。

原生导出脚本连接专用的本地 Blockbench 调试实例（9337 端口），不应连接用户正在编辑其他文件的实例。导出前重新运行构建脚本，避免重复叠加动画地面校正。
