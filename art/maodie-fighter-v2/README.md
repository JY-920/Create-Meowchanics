# 耄耋格斗手 v2：Blockbench 预览阶段

打开 `maodie_fighter_v2.bbmodel`，动画列表内包含护脸待机及七种战斗动作。双击 `preview.html` 可在浏览器查看 Blockbench 原生逐帧截图，切换动作、慢放 / 实际速度、暂停并拖动时间轴。`previews/*.gif` 是 0.25 倍速演示，不代表游戏实际出招间隔。

模型保留原版猫头和 16 像素长躯干，将腰背拆为两段前倾；前肢有肘关节、后肢有膝与踝，尾巴分三段。沿用 Minecraft 原版橘猫 red.png（旧 butter_cat.bbmodel 内名为 yellow_cat 的图片实际是黑白猫，因此没有使用错误的旧图片）。逐面映射保留完整猫爪和尾巴，包括封闭底面；没有重新绘制纹理。

| 动作 | 预览时长 | 设计 |
| --- | --- | --- |
| 普通挥拳 | 0.28 秒 | 左直拳、腰背扭转、迅速回收 |
| 上勾拳 | 0.36 秒 | 下潜蓄势、右拳向前上方挑起 |
| 连续出拳 | 0.68 秒 | 八次交替快速出拳 |
| 格挡 | 0.32 秒 | 双拳护脸、受击后躯干回弹 |
| 后撤 | 0.34 秒 | 护脸退步，保留后撤根位移 |
| 回旋踢 | 0.54 秒 | 转身、右腿伸展、尾巴平衡 |
| 腾空下砸 | 0.72 秒 | 压低、跃起、双拳下砸、屈膝落地 |

验证：1052 个 UV 采样点全部不透明；Blockbench 原生导入 21 个立方体 / 20 个骨骼 / 8 段动画。120 Hz 脚底采样报告见 `animation-contact-validation.json`。骨骼采用 Blockbench ZYX 旋转顺序，关键帧为 60 Hz，保留 0.07 像素插值安全余量。

## 后续游戏接入要求（本阶段未实现）

- 第三次抚摸开始气场，气场期间持续哈气并震屏。
- 从博古架正前方出现，而不是侧面。
- 只捕获野生猫，只有野生猫可变为 Boss。
- Boss 永久保留 Boss 身份，不主动还原普通猫；不显示名字。
- 战斗采用这套新动画，极快反应、追踪和移动；命中判定同步动画，不能简单走动绕开攻击。
- 继续使用地面旋转气流着色器，不改成原版粒子。
