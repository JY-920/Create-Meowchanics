# 耄耋格斗手 v3：参考视频后的动作改版

`maodie_fighter_v3.bbmodel` 是本版可编辑 Blockbench 源文件。`preview.html` 默认以原速播放「连贯实战演示」，可以切换单招、慢放、暂停或逐帧查看。旧 v2 文件保留在旁边目录，没有覆盖。

## 模型

- 身体从上一版两段共 16 像素改成 12.6 像素连续弧形躯干，12 段共享顶点的封闭网格，没有独立腰部断口。腰胸旋转统一到该网格的骨骼；不是把两个方块再叠起来。
- 保留原版猫头与橘猫纹理；肩臂从头侧降到胸口，肩关节比头部中心低 3.6 像素。
- 后腿总长从 8 像素减到 5 像素，上段嵌在身体中；取消独立脚掌。
- 拳头和尾巴所有面完整，UV 不采透明区域。

## 视频参考与动作

已本地分析用户提供的约 8 秒、30 fps 视频，包括 4 fps 全片接触表，以及 3.0–4.2 秒的逐帧爆发段。视频的启发是大幅沉身 / 摆动、肩胯带拳、拳头突然冲出后迅速回收，而不是只有前臂重复摆动。

本版用 120 Hz 关键帧制作：不对称的蓄力 / 爆发 / 急停节奏，躯干扭转、整身前冲、侧闪、短暂挤压拉伸和夸张的出拳伸展。此效果是本模型自己的动作设计，不声称与参考逐帧完全相同。

| 动作 | 时长 |
| --- | --- |
| 灵动架势 | 0.80 秒循环 |
| 爆发直拳 | 0.24 秒 |
| 上勾拳 | 0.34 秒 |
| 高速连续出拳 | 0.72 秒，八次交替出拳 |
| 急停格挡 | 0.26 秒 |
| 闪身后撤 | 0.28 秒 |
| 爆旋回旋踢 | 0.46 秒 |
| 腾空重砸 | 0.62 秒 |
| 连贯实战演示 | 3.41 秒循环，含短距离复位衔接 |

连续实战用于展示节奏，不代表最终游戏 AI 的固定招式顺序。原速视频为 `previews/combat_flow.mp4`；GIF 用于慢放，GIF 时间精度有限，准确时序以原速视频、网页及 Blockbench 时间轴为准。

## 边界

本轮仍是美术与动画预览。没有改动 Java 运行源码、JAR、配置或存档。震屏 / 持续哈气 / 架子正前方召唤 / 野猫限定 / 永久 Boss / 不显示名字 / 实战速度与命中逻辑等游戏改动，留待新动作定稿后接入。
