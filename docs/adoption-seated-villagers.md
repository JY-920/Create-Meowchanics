# 领养箱：坐垫职业奖励

- 识别同高度东、西、南、北四个紧邻方块上的 Create 坐垫，颜色不限。
- 必须有活着的成年职业村民作为坐垫实体的乘客。旁边站立的村民、幼年村民、失业村民和傻子不参与。
- 每个有效坐垫提供一份职业资源，最多四份。同职业多位村民也分别生效。
- 原版 13 种职业各有五档资源池，含该职业收购或出售的物资；猫咪品质每 20 点提升一档，高档有 25% 概率回退一档，数量随品质增加。非堆叠物品只给一个，图书管理员附魔书沿用现有随机附魔实现。
- 其他模组新增职业暂时给交易货币绿宝石，不混入其他职业的物资。
- 无有效坐垫职业村民时，沿用原来的品质分档随机奖励；领养时间不变。
- 完成领养时才检查乘客，不在每 tick 扫描。所有奖励能放下才消耗猫饼，否则保留猫饼并等待输出空间。
- 不读取/改变村民等级、交易库存或经验，不执行探索地图交易的结构搜索。

回归检查：无村民保持旧行为；一侧职业限定；四侧不同/相同职业均有对应奖励；无职业与未骑乘不生效；输出满时猫饼不丢失；两端存档重进正常。
