# 街舞猫 Blockbench 动作预览

当前文件：`cat_thomas_flare.bbmodel`；动画：`animation.cat.thomas_flare`。
旧的 `cat_street_dance.bbmodel` 保留作历史稿，不是当前动作。

## 当前设计

- 2.4 秒循环，145 个采样姿势；四肢、头、身体、两段尾巴共八个骨骼，11 个方块部件。
- 按用户最新要求，前腿恢复单根骨骼和完整贴图，不再拆分上臂与前爪。
- 后腿独立高踢、低扫，髋部绕支撑区域回旋，前腿交替离地让位；头部不随身体整圈旋转。
- 身体使用八个导向姿势和连续四元数曲线过渡，避免侧撑时由投影轴接近退化而突然翻转。
- 翻到正面时躯干下沉 1.8 像素，侧向翻转过程中增加平滑下沉，头部高度不随这次下沉一起降低。
- Euler 关键帧选择相邻的等价角度分支，减小跨角度边界时跳动的风险。

## 验证与状态

已用 Blockbench MCP 检查翻转中间帧、正面姿势和完整循环的落地高度。身体角速度峰值从修改前约 2207 度/秒降至约 414 度/秒；这是预览动作的比较，不是游戏性能指标。

骨骼结构已回到八骨骼。脚部插值的落地误差小于 0.01 像素，躯干及后腿保持在地面以上。

`build_thomas_flare.js` 为 Blockbench 环境内的重建脚本，不应直接作为普通 Node.js 脚本运行。

本源动画现已接入 Forge / NeoForge，游戏以二倍速播放，即 1.2 秒一圈。Blockbench 文件保留 2.4 秒的原始时间轴，避免重复加速。资源转换、循环、撑地和套装变换已通过自动检查；游戏包已构建部署，实际游戏视觉效果仍需启动实例检查。详见 `../cat-street-dance.md`。
