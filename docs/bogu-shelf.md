# 博古架

Forge 1.20.1 / NeoForge 1.21.1，有无机械动力均可使用。

创造模式在“猫咪养成”物品栏取出“博古架”，或 `/give @s laowu:round_bogu_shelf`。暂不提供合成配方。

底部中间为定位格，需空出左右各一格、向上两格的 3×3×1 空间；朝向随玩家水平朝向确定。任何占位有障碍就整体拒绝放置。用木斧可挖掘，拆任意部分只掉一件；创造拆除不掉落。

完整架子会自动吸附定位格中心三格球形范围内最近的野猫，安置在右侧大空位。每个架子只安置一只，不替换已有猫；不吸附宠物猫、牵绳猫，以及正在骑乘、被扫描查看、压扁或巨大化的猫。约每半秒检查一次，不加载范围外的未加载区块。

安置后默认坐姿，脚掌贴住层板。右键猫咪展示半秒哈气，随后自动恢复坐姿；服务器禁用哈气时仍只展示坐姿。架子自身没有右键操作。喂食、套装、扫描仪、猫袋等物品交互保持原有路径；驯服猫或拆架会安全释放，恢复安置前的坐下指令。

普通空手主手右键三次会开始耄耋召唤，不需要蹲下，也不需要每次间隔半秒。八秒未继续抚摸会重新计数；同一服务器刻的重复事件及副手不会重复计数。第三次先展示三秒、半径四格的地面旋转气场，再召唤格斗手。空间不足会提示腾出空间，不吞掉原猫；战斗结束恢复原猫及其数据，并进入五分钟再次召唤冷却。

架子持有的是真实猫实体，不复制/存入新猫 NBT。退出保存和读档会保留猫与座位，短暂哈气不跨读档延续。展示缩放仅影响客户端整只猫（含套装）的渲染，不改变原属性、真实尺寸或离架后的大小。吸附落点允许猫的完整碰撞箱触及本架装饰边条，但外部方块和实体仍会阻止吸附。

猫袋仍可正常收纳架上的猫，快照保存安置前的坐下指令。取下时在四周寻找有支撑、无危险和碰撞的落点；完全封死时保持当前位置，不传送进天花板。多格放置对每一格检查服务器交互保护。

按键：强化 Alt / 飞扑 X / 哈气音量 V 保持不变；下降固定左右 Ctrl，不再出现在按键配置；物品显示调节器默认未绑定。旧 options.txt 里的自定义/已有 K 绑定保留，可在控制设置中清空或重新设置。
