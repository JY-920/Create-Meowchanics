# 职业平衡与分类调整（Forge / NeoForge）

- 激光笔有序合成：自上而下为电子管、猫锭、铁锭。染色配方不变。
- 雷管猫致命自爆：该职业攻击伤害 × 5（原为 × 10）。
- 飞行员猫攻击伤害：2.00 ×（2 + 0.08 × 战斗力属性），原系数为 1.25，即在原伤害基础上提高 60%；攻击间隔和套装属性加成不变。
- 采蜜猫攻击伤害：0.85 ×（2 + 0.08 × 战斗力属性），原系数为 1.05，约降低 19%。攻击间隔、缓慢效果不变；世界属性倍率仍按原逻辑应用。
- 归属预览头像及边框一起上移约 16 个头像纹理像素，按现有头像比例换算为 0.76 格；这是世界空间标记，屏幕上的实际像素随观察距离变化。
- 激光笔、猫咪收纳盒和全部七种职业套装统一显示在猫咪养成创造物品栏，不再显示于本体栏。玩家穿戴的四件盔甲不移动。
- 两端中文、英文公式说明同步更新；Shift 数值示例继续直接读取职业计算结果。
