# 远程职业弹幕击退规则

Forge 1.20.1 / NeoForge 1.21.1 同步：

- 机械猫激光、采蜜猫蜂蜜飞弹、雷管猫投掷雷管的范围伤害不造成击退。
- 钓鱼猫保留原有钓钩击退。
- 物流猫包裹仍仅提供增益，不造成伤害或击退。
- 本次不改变近战、雷管猫临死自爆、玩家发射的猫饼及其他模组攻击的击退。

## 实现边界

前三类弹幕使用 `CatProjectileDamage.hurt`，沿用原来的原版伤害来源、伤害量、减伤、受伤事件及仇恨流程。蜂蜜飞弹的缓慢 II（3 秒）、雷管范围和距离衰减不变。

只在本次同步伤害调用内，通过各加载器的 `LivingKnockBackEvent` 取消当前受击目标的击退；雷管原有额外 `push` 同时删除。不清零受击者原速度，不添加抗击退属性，不写入存档标志，避免破坏行走、跳跃和其他攻击。线程隔离、嵌套调用及异常退出均恢复上一层状态。

统一伤害入口保留 `allowKnockback` 参数，后续饰品可以恢复原版击退流程；目前所有上述弹幕传入默认关闭值，本次未注册或实装饰品。

## 验证

`tests/run-global-world-config.ps1` 运行真实配置与重置草稿辅助方法，覆盖七职业全部 128 种全局锁组合、只读权限、原始默认值、不自动保存，以及击退上下文的嵌套、例外放行、失败伤害、异常和线程隔离。

`tests/career-damage-wiring.mjs` 检查三个弹幕入口、双端事件订阅、钓鱼例外、雷管额外推力移除、配置按钮可见性与翻译。

构建和离线检查不能替代实机视觉/战斗验证。进游戏可分别检查：

1. 管理员修改多个套装系数后点「恢复默认」，确认预览更新；返回不保存不会改变实际配置，保存才生效。
2. 全局固定部分职业后重置，确认固定项不变，其他项复原。
3. 三类远程弹幕命中普通敌人只扣血/施加原有效果，不推开；钓鱼猫仍推开。
4. 同一目标随后被玩家或近战猫攻击，仍按原版规则击退；原有移动和跳跃不被清零。
