# 外观词条属性加成（Forge / NeoForge）

外观效果、稀有度、升级资格和外观互斥规则沿用原有规则。当前十二种外观词条都有正数属性加成。

| 词条 | 额外属性 |
| --- | --- |
| LOLI猫 | 生命+10、幸运+5 |
| Him猫 | 战斗力+15、智力+5 |
| 以撒猫 | 幸运+10 |
| 圆头猫 | 耐力+10 |
| oiiai猫 | 速度+10 |
| 街舞猫 | 速度+10、耐力+10 |
| 琵琶行 | 智力+10、幸运+10 |
| 穿靴子的猫 | 战斗力+10、速度+10 |
| 猪咪 | 生命+10+2×(等级−1)、耐力+5 |
| 滚木 | 速度+15 |
| 彩虹猫 | 速度+10、幸运+20（保持原值） |
| 猫又 | 战斗力+20、智力+10（保持原值） |

猪咪只有生命加成随等级成长，1级+10，7级+22；耐力固定+5。
其他外观词条仍不可升级。非升级优良词条的七级图标仅为显示样式，不会七倍叠加。

实现统一入口：CatTrait.appearanceAttributeBonus，CatAttributeEffects.effectiveValue 的词条循环只累计一次。
移除原有彩虹猫、猫又的独立累计分支，避免重复加成。
当前面板与实际能力共享有效属性计算；不改变存档基础属性和属性上限，繁育不会将词条数值重复写入基因。
猪咪当前/详细/下一级描述均使用实际公式参数；双端中英文描述同步。

测试：tests/CatAppearanceBonusRegression.java 编译真实 CatTrait、CatStat、CatTraitSlot、CatTraitRarity，
以 tests/appearance-stubs 隔离仅文本与资源标识的 Minecraft API，覆盖所有词条、六属性和1–7级，
并验证猪咪描述参数及等级边界。此测试不替代游戏内视觉与实体战斗验收。
