# 航空箱与激光笔（Forge / NeoForge）

## 航空箱

- `laowu:cat_carrier`：右键存入一个猫饼，蹲下右键取出；猫咪全部物品数据保留。
- 容量 8000 mB，仅容纳哈气，六面均可连接流体管道。有猫时每 5 tick 产生 100 mB，即 400 mB/秒；为两只猫向储罐产气合计速率的一半，空箱约 20 秒装满。作为独立机器，不受世界“猫咪哈气”开关控制。
- 航空箱物品悬浮描述直接显示“哈气：当前值 / 8000 mB”和“猫咪：有 / 无”，无需 Shift；读取破坏后保存的方块实体数据，未使用的箱子显示 0 与无猫。
- 不播放声音。内部猫是只渲染、不加入世界的客户端预览，不参与 AI / 战斗 / 掉落；缩放为 0.55，防止嘴巴穿出箱体。
- 破坏时掉落携带猫饼和液体数据的航空箱，重新放置恢复。创造模式破坏非空箱也保留内容物。
- 护目镜显示储量；液体变动至多每秒同步一次，猫饼存取立即同步。
- 配方：第一排三个铁锭；第二排玻璃板、铁栏杆、玻璃板；第三排三个黄铜锭。

## 激光笔

- `laowu:cat_laser_pointer`：最长 32 格，射线受实体方块阻挡，实体瞄准框向外扩 0.6 格；实际命令在服务端判定。
- 右键地面：指挥自己周围 32 格内的猫前往，到达后结束移动指令，不让猫坐下，恢复正常跟随/战斗行为；有效指令最长 30 秒。
- 右键生物：指挥攻击。职业猫沿用职业伤害和攻击方式，无套装猫使用普通近战；物流猫不攻击。
- 不指挥其他玩家的猫，不打断坐垫/载具上的猫、猫饼或正在查看面板的猫。不攻击玩家；宠物按项圈颜色判断友方，同色拒绝攻击，异色可被指定（见 cat-collar-teams.md）。
- 目标/猫超过主人 96 格、死亡、离线，或猫被命令坐下时，攻击指令失效；不加载远处区块。初始指挥半径和激光长度仍为 32 格。
- 目标白色框只发给操作者，不使用全局发光状态。射线为仅操作者可见的客户端实心渲染，每帧使用插值视点重新计算，不发送射线数据，不受服务端 20 tick 同步频率限制；命令仍由服务端判定。右键不挥手。
- 蹲下右键切换本机猫咪归属预览（猫咪轮廓颜色、主人头像及队伍色边框，不高亮主人）。主手激光笔、副手染料时优先给激光换色；生存模式消耗一个染料。
- 配方：猫锭、电子管、铁锭竖直排列。

## 验证

构建验证不等于实际游戏渲染验证。双端建议回归：四方向放置；猫饼完整 NBT 与液体拆放保存；创造模式破坏；管道抽取；服务器重进；两名玩家各自的猫与标记隔离；职业攻击及坐垫豁免；染料颜色；玻璃透明和第一/第三人称模型位置。
