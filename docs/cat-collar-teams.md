# 项圈队伍与激光笔归属预览

- 使用原版持久化并同步的项圈染色值作为队伍 ID（16 色，默认红色），无需新 NBT、计分板队伍或额外数据同步。染料给猫换项圈颜色就是换队。
- 同色已驯服宠物是友方，不因主人不同互相索敌或造成伤害；保护同时覆盖职业弹幕和范围伤害。狗按自己的项圈颜色参与，其余无项圈的原版驯服宠物按红色处理。
- 不同色是中立而非自动敌对。保护主人、反击、行为词条或激光笔指令仍决定是否进入战斗；不会新增异色主动索敌扫描。玩家本人仍不作为职业猫目标。
- 激光笔只指挥自己的猫；目标为宠物时，每只猫分别检查项圈关系，同色猫忽略攻击指令。重新染色后重新检查当前目标与后续伤害。
- 蹲下右键激光笔切换本机预览；显示当前加载、64 格内宠物猫的原版染色轮廓，以及头顶主人头像/队伍色边框。不高亮主人。不设置服务器实体发光位，不改计分板。
- 主人在线时使用玩家列表的皮肤；无法获取玩家皮肤时显示 UUID 对应的默认头像。预览跨世界自动失效。
- 激光笔与 1 个染料在工作台合成更换激光颜色；副手染料不再用于染色。蹲下右键始终切换预览；染激光不等于染猫的项圈。
- 笔身使用固定 32 格瞄准方向，直接构建相机/世界向上的正交朝向基准，不再绕晃动后的手部轴做 yaw/pitch。光束仍追踪真实命中位置，出口为模型 (0.5, 1.5, 8) 像素；命中点落在笔口后方时隐藏光束，禁止反向发射。物品栏/掉落物不发射激光。
- 头像中心位于猫咪顶部上方 0.60 格，比初版上移 0.15 格。
- 职业战斗脱离距离、原版猫跟随传送阈值统一为 96 格；激光指令在主人 96 格以内继续有效。坐下/坐垫猫不因此强制返回，其他宠物的原版跟随距离不改。

## 回归清单

### 2026-09-09：团队优先

- 同色项圈：无论主人是否相同，均为友军。
- 同一主人、异色项圈：可通过激光指令、反击等交战；主人处于原版队伍也不阻止其内部不同色猫队混战。
- 不同主人、异色项圈：若两个主人同属一个原版计分板队伍，则为友军；否则为中立，可交战。主人队伍不改变猫的项圈颜色及预览颜色。
- 不会仅因异色就自动攻击。激光笔仍只能指挥自己的猫，不扩大控制权。
- 近战保护、物流选择增益接收者、在途增益命中时均使用同一友军规则。换队后取消敌方支援。
- 猫饼常显主人、职业、成猫/幼猫、团队颜色。新捕获猫保存已知主人名字；信息素猫粮机械手驯养也保存名字。旧猫饼优先显示当前可解析的玩家名字，否则显示保存的名字或 UUID，不执行网络查询。

双端构建、生产 SRG/Mojmap 方法别名核查；双玩家同色不伤害；异色反击/激光指定；飞行/喷火/机械/钓鱼/蜂蜜/雷管弹幕；战斗中改色；蹲下开关预览及染色优先；头像方向；第一/第三人称、左右手、不同 FOV 与视角晃动；退出世界再进；多人仅本机可见。游戏实测与光影效果需要在客户端确认。
