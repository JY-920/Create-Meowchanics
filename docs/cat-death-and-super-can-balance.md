# 死亡惩罚与超级罐头（2026-09-10，双端）

- 职业猫死亡变为猫饼时，从六项基础属性中等概率选择一项，扣20，最低0。
- 属性上限、其余五项基础属性不变；不改变“生个小病”等独立词条的死亡效果。
- 六种超级猫罐头将对应基础属性和上限分别补到至少90，超过90的数值保留。
- 例：基础80/上限100→90/100；95/100→95/100且不消耗；50/70→90/90。
- 普通罐头+1、金色罐头+10仍受原上限限制。超级鱼干不变，全局属性最大值仍为100。
- 手动喂食和猫饼/机械手部署共用 CatAttributeCanItem.train，执行相同规则。
- 不自动补偿此前死亡扣除的上限，也不自动降低存档已有的100属性。
