# 驯养猫死亡处理配置

适用：2.2.1 的死亡处理更新，Forge 1.20.1 / NeoForge 1.21.1。联机客户端与服务端需同时更新本次构建。

## 游戏内

按 V → 世界设置 → 死亡设置，点击“死亡处理”循环选择：

| 选项 | 死亡结果 | 物品栏与饰品 |
| --- | --- | --- |
| 不掉落 | 不生成猫饼 | 正常掉落，不销毁 |
| 掉落猫饼掉落物（默认） | 一个猫饼物品 | 保存在猫饼内，不重复掉落 |
| 转变猫饼生物 | 一只扁平的猫饼生物 | 保存在生物内，不重复掉落 |

后两项才显示“死亡扣属性”和“每次扣除点数”。隐藏不会清空已有设置；切回后保留原输入。隐藏的无效数字不会阻止保存“不掉落”，也不会覆盖原本有效的扣除值。

OP 等级 2 及以上或单人世界主人可修改。全局强制覆盖时，选择器锁定；普通玩家只读。

## TOML

存档的 serverconfig/laowu-server.toml 根级：

```toml
# 0=不生成猫饼但正常掉落装备，1=猫饼物品，2=猫饼生物
cat_death_outcome = 1
cat_death_attribute_penalty_enabled = true
cat_death_attribute_loss = 20
```

实例/服务端 config/laowu-global.toml 的同名模式键默认 -1，表示沿用存档；0、1、2 强制指定模式。原死亡扣属性开关的全局写法仍为 -1/0/1，扣除点数的全局写法仍为 -1 或非负整数。

## 边界

- 新模式仅改变已驯养猫的死亡结果，含无职业猫及幼猫。未驯养职业猫保持原猫饼物品规则。
- 猫饼物品与生物共用保存/还原数据：主人、名字、外观、年龄、词条、基础属性、上限和随身物品保留。每次死亡至多随机扣除一项基础属性，最低为 0；上限不变。
- 猫饼生物使用既有扁平猫状态，可按原有铲取/收纳方式处理；不新增一个独立物种。若其他机制拒绝新生物加入世界，会回退为同一份猫饼物品，避免数据丢失。
- 遵守 doMobLoot。原版图腾、九命等阻止死亡的效果，以及雷管最后自爆、蟑螂分裂的既有优先级不变；分裂成功仍使用原分裂规则。
- 不改变“生个小病”等独立词条效果。不追溯返还此前扣除的属性。
- 旧存档缺少模式键时默认补为 1，不重置其余配置；不会自动修改玩家脚本。
