# 猫咪死亡属性配置

适用版本：Forge 1.20.1 / NeoForge 1.21.1，2.2.0 本地更新。

## 游戏内设置

按 V → 世界设置 → 死亡设置。选择猫饼物品或猫饼生物时，显示扣除开关与点数，修改后点「保存」。三种死亡结果见 [死亡处理配置](cat-death-outcome.md)。
单人世界主人或 OP 等级 2 及以上可修改；普通玩家只读。

## 存档 / 服务端配置

编辑存档目录下的 `serverconfig/laowu-server.toml` 中以下根级配置。旧配置缺少这些键时由加载器补入默认值，不重置其他设置。

```toml
# true 开启，false 关闭；默认保持原规则。
cat_death_attribute_penalty_enabled = true
# 每次随机一项基础属性扣除的固定点数；非负整数，默认 20。
cat_death_attribute_loss = 20
```

关闭开关或把点数设为 0，均不执行这项扣除。修改只影响之后发生的死亡；不会补偿旧猫饼已经扣除的属性。

## 全局覆盖

实例 / 服务端的 `config/laowu-global.toml` 同名配置使用数值覆盖：

```toml
# -1 沿用各存档，0 强制关闭，1 强制开启（此文件不是 true / false）。
cat_death_attribute_penalty_enabled = -1
# -1 沿用各存档，0 不扣除，其他非负整数强制指定扣除点数。
cat_death_attribute_loss = -1
```

全局覆盖会锁定游戏内对应选项，但不改写存档原值；恢复 -1 后继续使用存档原值。联机只以服务端的配置为准，客户端本地全局文件不能改变服务端规则。

## 行为边界

- 每次从六项基础属性中等概率选择一项；扣除的是点数，不是百分比，也不是六项同时扣除。
- 最低扣到 0；其他基础属性和六项属性上限保持不变。
- 适用于死亡后生成猫饼的已驯养猫（含无职业猫、幼猫）和职业猫；不会改变原有掉落资格。
- 关闭扣除时仍正常保存主人、年龄、外观、名字、物品栏与饰品，并清理死亡状态以正常复活。
- 普通捕捉 / 收纳不扣属性；未真正死亡、蟑螂分裂成功和关闭生物掉落规则的行为不变。
- “生个小病”等词条独立效果、蟑螂分裂的属性继承比例不受这两项配置控制。
- 接受 0～2147483647 的整数；网络提交拒绝负数、错误 NBT 类型和不完整数据。文件里的越界整数由加载器按区间纠正。
