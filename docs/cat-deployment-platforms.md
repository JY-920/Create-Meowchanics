# 猫咪部署台与弹射部署台

适用：Forge 1.20.1 / NeoForge 1.21.1；当前构建版本 2.2.2。

## 使用

- 猫咪部署台：`laowu:cat_deployment_platform`。
- 猫咪弹射部署台：`laowu:cat_ejecting_deployment_platform`。
- 两种机器均只储存哈气，容量 4000 mB。可用哈气桶或流体管道灌入，空桶或管道取出。
- 手持猫饼右键放入，也接受顶面掉落的猫饼和物品自动化。只容纳一个猫饼；空手右键取回未部署的猫饼。
- 每次成功还原消耗一个猫饼和 250 mB 哈气，沿用完整猫咪数据还原，保留主人、职业、属性、词条、背包与饰品。
- 燃料不足、生成空间被堵、目标无效或目标区块未加载时不会扣除猫饼和哈气。机器自动重试，不强制加载区块。
- 挖掘或蹲下扳手拆除后，液体和待部署猫饼保存在方块物品中；物品提示显示哈气储量。重新放置恢复内容。

## 弹射目标

1. 手持弹射部署台，蹲下右键目标方块选点；蹲下左键取消选点。
2. 松开蹲下键，正常放置机器。机器和目标须沿同一 X 或 Z 轴，不能是正上方；距离遵守机械动力的弹射距离配置（默认 32 格）。
3. 供给哈气和猫饼，猫咪还原后沿机械动力活体弹道弹射。无需额外旋转动力。

持有已选点的机器或看向已放置的机器时显示目标框。挖起机器后保留相对目标偏移；在新位置放置会平移其目标。重新蹲下选点可以覆盖旧目标。

落点按选中方块的顶面计算，并在发射前检查猫咪占用空间。弹射遵守实体碰撞，不穿墙、不传送；路径途中被挡仍可能提早落地。天空猫等自主移动在空中短暂停止覆盖弹道，落地后恢复；公开饰品/词条 tick 事件继续执行。

当前未指定合成配方，两个物品已加入创造物品栏；本次未擅自添加配方。
