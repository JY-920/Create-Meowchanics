# 猫编辑台新版验收记录（2026-10-04）

版本：Forge 1.20.1 / NeoForge 1.21.1，公开版本号保持 2.2.2。

## 操作

- 机器旁同层相邻坐垫上放置自己的猫；多个目标仍固定选择一只。
- 左侧第一页编辑词条。最多四条紧密排列，每行白格用于装卸瓶装词条；最后仅显示一行安装按钮。
- 拆卸免费。安装按稀有度在服务端执行指定风险；悬浮安装时顶级隐藏 NOW/MAX，次级隐藏 NOW。
- 第二页左右箭头选择原版猫材质；方块样本优先于该行列表选择。每行悬浮显示完整部位和材质名称。
- 修改立即展示在独立预览猫上。还原取消尚未确认的修改，恢复当前已保存外观；不删除此前保存的外观。
- 确认后每个实际改变外观的样本消耗一个方块，剩余材料归还背包（满则掉落）。等待回包期间禁用外观修改，防止草稿不同步。
- 关闭界面归还临时槽物品；预览、还原和无变化的重复确认不额外扣料。
- 瓶装词条保留原图轮廓，仅19个液体像素按四档稀有度改变颜色，GUI、手持和掉落共用相同渲染。

## 验证

- Forge 服务端16项通过；NeoForge服务端17项通过：概率边界、损失范围、零下限、属性上限保护、免费拆卸、非法装入无损、重复包、所有者/坐垫/距离、紧密排列、预览与提交、余料守恒、重复确认。
- 双端真实客户端最终显式 PASS：四词条、扫描器卡片提示、四档风险遮罩和瓶子颜色、12个外观选项、独立实体预览、源猫不变、320×240边界、确认期间拒绝新草稿及回包清理。
- 单例部位样本耗尽后暴露旧全身样本、延迟确认清除新草稿两项均先复现失败再修复。

- 正式构建使用普通 build，执行饰品API、词条API、23270项饰品检查及发布隔离；测试资源不进入模组包。
