# 猫编辑台（首版验收）

方块ID：`laowu:cat_editor`；拆出的词条物品：`laowu:cat_trait_token`。

## 安置猫咪

在编辑台水平紧邻的一格放置机械动力坐垫，让自己驯服的猫坐上去。右键编辑台打开界面；多只符合条件时稳定选择其中一只，界面打开后不会自动换猫。猫离开坐垫、死亡、主人变化、机器被拆除或玩家走远时不能继续编辑。

## 外观页

放入一个方块样本，选择全身或头部、双眼、耳朵、口鼻、前后身体、前后肢、尾巴中的单个区域，点击应用材质。每次应用消耗一个样本，材质映射复用现有猫咪遗传外观系统，不改变属性、词条、职业、主人和物品栏。界面显示猫咪预览。

## 词条页

- 点击现有词条旁的“拆出”，整条词条及原始等级移入输出槽。输出槽有物品时不会继续拆出。
- 将词条物品放入输入槽，点击“装入词条”。成功后消耗该物品；重复、冲突、四槽已满、定义停用或缺失时保留输入。
- 不自动合并等级、不覆盖原词条。支持注册过的KubeJS词条；缺失定义的已保存词条也能拆出保管，重新启用定义后再装入。
- 词条物品描述显示名称、等级、ID与可用效果说明。

三个临时槽在两页均可见；关闭、离开或断线时归还物品，背包满则掉落在玩家身边。Shift点击可快速转移；输出槽不能放入物品。

本版采用提供的原始模型、UI图集与词条图标，暂不添加未指定的配方、耗气或应力要求。创造栏可获取编辑台。
