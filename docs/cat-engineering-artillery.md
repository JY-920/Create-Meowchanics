# 工程猫炮台战斗

内部构建：2.1.4-dev.accessories.12；Forge 1.20.1 / NeoForge 1.21.1 同步开发。公开版本仍为 2.1.4。新增[三种弹药与辅助职业](career-support-and-munitions.md)。

## 行为

- 工程猫是远程炮台职业。有效目标进入 32 格且射线畅通、脚下着地并有部署空间时部署大炮，猫咪坐在炮后坐垫上，底板后延支撑坐垫。
- 部署准备 16 tick 后发射齿轮。低智力猫近敌不退炮；有效智力至少 80 时优先在 14–18 格范围（约半射程）立炮，距离小于 8 格或大于 24 格时收炮退后/追近。超出 32 格时所有工程猫收炮追近。
- 智力包含职业 +20 及词条/饰品加成。已部署至少保持 32 tick，收炮后至少等待 8 tick；寻找位置最多 48 tick 或确认无可用退路后，仍可在射程内开火。冷却跨拆装保留，准备就绪先打一炮再判断换位。新生成/刚下炮未落地不误判成无退路。
- 开启主动攻击敌对生物时，普通工程猫的自动索敌范围同步为 32 格，半射程架炮不丢失目标；长毛护体既有视野惩罚仍保留。
- 射线被墙持续阻挡 20 tick 时，允许收炮寻找能射击的位置，不穿墙开火。空间不足或在水中时不强行部署。
- 激光笔仍能给炮台中的猫更换攻击目标；指示移动地点会先收炮。坐下命令、换装、死亡、失去目标或打开猫咪面板均会结束部署。
- 保留普通坐垫摇曲柄的工作功能，不在工作坐垫上部署大炮。「上天猫」工程师有战斗目标时落地，战斗结束后恢复原有词条/指令逻辑。

## 当前默认配置

| 配置 | 默认值 |
| --- | --- |
| 伤害系数 K | 3 |
| 基础间隔 / 速度缩短系数 / 最短间隔 | 50 tick / 0.25 / 20 tick |
| 生命值 / 护甲 / 韧性加成 | +30 / +12 / +5 |
| 战斗力 / 幸运 / 智力属性加成 | +10 / +40 / +20 |

工程套装加入现有全局 TOML 和存档内「套装配置」GUI，沿用锁定、恢复默认和同步逻辑。职业参数可调，不另加固定的第二层伤害或暴击倍率。

全局属性倍率为 1、没有其他加成时：

| 六项基础属性 | 单发普通伤害 | 攻击间隔 | 暴击率 | 暴击伤害倍率 |
| --- | --- | --- | --- | --- |
| 50 | 20.4 | 38 tick（1.9 秒） | 18.2% | 1.7 倍 |
| 100 | 32.4 | 25 tick（1.25 秒） | 27.2% | 2.2 倍 |

伤害为命中结算前的数值，最终还受目标防御、饰品、词条和配置影响。伤害公式仍是 (2 + 0.08 × 有效战斗力) × K；暴击率由幸运、暴击伤害由智力提供。切换目标不重置装填冷却。

## 模型、弹丸与兼容

直接调用 Create 的 schematicannon 底座、连接件和炮管模型；以原模型 (8,15,8) 轴心瞄准，炮管具有开火后坐效果。炮后使用项圈团队色坐垫（中心后移 1.05 格、座面高 0.25 格），底板向后延伸。三种弹丸分别使用 create:cogwheel、create:large_cogwheel、create:shaft 三维模型，不朝向摄像机。

大炮是临时战斗乘坐实体，不放置/破坏世界方块，不消耗或掉落玩家的蓝图炮、坐垫、齿轮。正常存档会连同乘客猫一起保存，重载后没有目标就安全收炮、保留猫咪，不能把乘坐实体设成 noSave。收纳、换装等操作后不会留下孤立大炮。

弹药按小齿轮（单体）→大齿轮（2.5 格范围）→传动杆（穿透多个生物）循环，拆装保留进度。从炮中心出弹，飞行上限 34 格、寿命上限 80 tick，不追踪、不破坏地形、不掉物品。检测实体初始重叠和整段飞行路径，避免贴脸、高速穿透漏伤；墙体会截断弹道，范围伤害不穿墙。传动杆每个生物只伤害一次，命中记录随弹丸保存。遵守团队和禁止攻击玩家的规则，默认无击退；弹簧饰品可恢复正常远程击退。沿用饰品/KubeJS 发射、伤害、暴击和追击接口，无新强制依赖。

工程套装的导入模型轴心独立于“预览职业”开关，启用战斗不会改变工具箱或摇曲柄动画的位置。医疗已启用辅助功能，仅音乐仍为预览职业。
