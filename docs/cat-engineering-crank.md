# 工程猫：坐垫摇曲柄

曲柄动画已随 accessories.7 部署双端。当前 `2.1.4-dev.accessories.12` 新增耐力应力输出，保留既有动画、[炮台战斗](cat-engineering-artillery.md)及[飞行员载人](cat-pilot-passenger-flight.md)。

## 使用

- 给驯养的猫装备工程套装，并让它坐在机械动力坐垫上。
- 在坐垫的正上方一格放置 `create:hand_crank`，曲柄安装在旁边方块的侧面。支持东、南、西、北四种方向，不识别朝上/朝下安装、阀门或运动装置上的坐垫。
- 猫咪侧身，双前爪分别握住把手杆上的两个位置，前后推拉并带动曲柄。约 0.5 秒伸手过渡后开始供能。
- 使用 Create 原生转速，猫咪供能时总应力容量为「有效耐力 × 128 SU」，不额外封顶，不消耗猫粮。容量按转速换算后写入真实动力网络，不是每 RPM 再提供 128 SU。保留玩家最后设定的转动方向；猫离开后恢复普通曲柄容量，猫咪加成不保存进方块存档。
- 离座、卸下套装或拆除曲柄后不再续摇，曲柄沿用 Create 的短暂释放/减速过程。不会消耗或改写坐垫、曲柄、套装及猫咪保存数据。
- 工作时中间长方形躯干和两个工具箱一起后移 4 个模型像素；头部的前后基准不再跟着整体后移，双爪握持位置保持不变。原套装模型文件没有删减。
- 曲柄升高时平滑站起，最高额外抬身 4 个模型像素；降低时恢复较低姿态。工作循环中躯干和工具箱保持既有固定尺寸（身体缩放固定 1/0.72/1），只做平移和旋转，仅腿、手臂调节长度。普通成猫后脚继续贴着坐垫。
- 起身和落下分别占半圈，使用五次平滑曲线，在高、低点都柔和换向。相比前一版集中在上半区起身，腿部每帧长度变化峰值从约 0.216 降至 0.143 像素，避免向上顶起过快；最高站姿不变。
- 工程猫现已开放[炮台战斗及套装数值配置](cat-engineering-artillery.md)，普通工作坐垫上的摇曲柄逻辑保持不变；医疗、音乐猫不受影响。

## 动画与坐标

使用用户已配置的 Blockbench MCP 建立专用工程；导入实际工程套装、Create 曲柄、坐垫模型和贴图作为参照，没有在游戏里再绘制一个假曲柄。

- [完整 Blockbench 工程](blockbench/cat_engineering_crank.bbmodel)
- [MCP 建模与动画重建脚本](blockbench/build_engineering_crank.js)
- [MCP 实际场景校验脚本](blockbench/verify_engineering_crank.js)
- [侧面预览](blockbench/cat_engineering-side.png)、[高位握持预览](blockbench/cat_engineering-upper.png)

保留原猫的 8 根骨骼和单根腿结构。Blockbench 制作躯干、头部、后腿和尾巴的循环动作，共 181 帧；游戏按曲柄实际角度采样，不按猫咪年龄计时。

两个握持点取自真实把手模型的 `Grip` 段，沿把手杆相隔 3 像素。复用 Create 的朝向与旋转变换，分别计算其世界位置，再转入猫咪渲染坐标，对两根前腿进行接触修正。加速、减速和反转均沿用曲柄自己的平滑角度。

坐垫骑乘高度使用实时实体位置计算，不硬编码两端相同高度。正常及大体型成猫保留 Blockbench 制作的身体位置，只修正前爪接触，避免固定伸手限制把已经后移的身体再次拉回。仅缩小后的猫（包含幼猫）在够不到握杆时才跟随抬起，前腿可达距离至少保留每帧实际制作的长度。幼猫分别处理头部 3/4、身体 1/2 缩放；后腿可达距离也保留每帧制作的伸腿长度，避免站起时被旧长度限制拉离坐垫。小体型需要越过腿部可达范围时仍允许短暂离座，不无限拉长四肢。大体型猫及 NeoForge 实体 scale 也进入坐标换算，后脚落点限制在坐垫范围内。

工作动画覆盖闲暇街舞/琵琶及 oiiai 自转，项圈和工程套装继续跟随最终骨骼。进出工作状态使用平滑过渡；每只猫独立的弱引用状态不写入 NBT，不保留整个世界。没有逐帧网络包或邻域生物扫描；服务端只维护原生曲柄操作，定期同步曲柄状态。

精简动作存放在 `assets/laowu/cat_animation_clips/`，不会被 GeckoLib 当作其动画格式读取，不新增前置依赖。缺失/损坏动作资源时安全回退普通姿态。

## 验证

- Blockbench 实际场景检查 721 个时刻，验证双爪接触、后脚不穿坐垫、身体和箱子尺寸固定；逐帧检查两个工具箱共 192 个渲染顶点相对躯干无漂移（误差小于 0.000005 像素）。高点两条手臂约 10.68 / 10.45 像素。
- `tests/run-engineering-crank.ps1` 双端各通过 8,790,481 项检查，覆盖四朝向、正反角度、幼猫/成猫、四档体型、四种实际骑乘高度、双爪接触及脚掌不穿坐垫；验证成猫保留完整后移、头部前后基准独立、抬身时躯干不拉伸、普通成猫站起时后脚贴住坐垫。最大接触误差小于 0.00006 像素。另通过资源缺失回退检查。
- 双端真实 Minecraft GameTest 校验坐垫定位、四个侧装方向、非法安装拒绝、真实曲柄供能、反转、离座停止、方块拆除和保持无职业战斗。与已有饰品/脚本测试合计各 3 项通过。
- 尚未进行完整整合包的图形客户端或多人联机验收；Blockbench 预览和数值测试不替代实机外观验收。

重建前先运行 `tools/prepare-engineer-reference.ps1`，通过 MCP 创建名为“工程猫摇曲柄”的空白 free 工程，再运行建模脚本；不要把重建脚本用于其他工程。从 Blockbench 保存工程后，执行 `node tools/export-engineering-crank.mjs --write` 机械导出双端资源。
