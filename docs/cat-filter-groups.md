# 猫咪过滤器：分组条件（双端）

## 判定顺序

1. 只接受拥有属性数据的猫饼，其他物品不会因为反向选择而通过。
2. 身份条件（成长阶段、主人、职业、名字）始终全部满足。
3. 属性组：只判断当前属性与属性上限两页中勾选的条件；可选全部 / 任意满足，再对整个属性组反向。
4. 词条组：选择的最多四个词条按全部 / 任意满足判断，可对整个词条组反向；词条等级不限。
5. 属性组与词条组之间可选全部 / 任意满足。没有启用条件的属性组和空词条组不参与，包括反向时。两组都空则只判断身份。

筛选结果的含义始终是“允许通过”，不是“保留”。连接销毁设备时，通过的猫饼会进入销毁线路。

## 界面

- 四页：当前属性、属性上限、身份/组合、词条。
- 当前属性范围为 0～300；属性上限仍为 0～100。旧范围超出 300 的部分在读取时收敛至 300，其余筛选条件不变，仅查看不改写原物品 NBT。
- 每项属性左侧有启用框；拖动范围会自动启用该项。取消勾选保留范围，但该项不参与匹配或父母择优目标计算。
- 属性页顶部配置属性组的全部/任意和反向；词条页顶部配置词条组逻辑。身份页配置两组的组合关系。
- 底部自动生成“允许通过的猫饼”说明，过长时截短；悬停可查看完整说明。物品悬浮描述使用同一规则说明。
- 保留词条左侧选择列表及右侧效果预览，名字输入、清空、确认、玩家背包均沿用现有操作。

## 配置示例

- 销毁未全到 90 的种猫：仅启用六项属性上限，均设 90–100；属性全部满足、开启反向；词条留空。六项都达到 90 的不通过，任意一项 89 的通过。
- 任意好词条：选猫又、彩虹猫；词条任意满足。
- 排除坏词条：选面团团、基因缺陷；词条任意满足、开启反向。
- 属性优秀或有好词条：属性六项上限 90–100、全部满足；词条选择好词条、任意满足；身份页将两组设为任意满足。

## 旧数据及繁育箱

- 数据版本升至 2，新增两页启用位和五项逻辑标志。旧过滤器自动将非默认范围设为启用，维持原有全部满足、非反向的结果；早期当前属性默认 0–100 的兼容迁移仍保留。
- 服务端通过容器数据同步启用位和逻辑；按钮发送明确的新值，非法按钮号不会越界。编辑期间不修改手持物品，关闭后由原容器流程保存，避免界面意外关闭。
- 三级繁育箱继续只根据属性上限择优，当前训练属性不改变基因评分。未启用的上限项默认朝 100 择优。
- 旧模式保留原来的逐项择优评分。使用任意/反向/组间或等新模式时，候选父母须满足上限组与词条组的逻辑，避免反向排除的猫被重新选中；当前父母不匹配时，符合条件的候选可以替换它。身份条件仍是硬条件。
