# 飞行员猫载人飞行

当前内部构建 accessories.17 增加 Ctrl 下降，解除时长和速度上限，精简 HUD；accessories.16 根据截图移除下环和连接件，仅保留包身环，腹部到下横杆留 3 像素空隙，并校准猫与玩家的相对悬挂高度。保留 accessories.14 的非空旧背包兼容入口与中心对齐，以及 accessories.13 的近战防护：套装额外 +30 生命、+7 护甲、+3 韧性，基础攻击间隔 40 tick。原 Create 动作和现有单环接触位置不变，见[平衡说明](career-balance-accessories.13.md)。Forge 1.20.1 / NeoForge 1.21.1 同步，公开版本仍为 2.1.4。

## 使用

- 手持机械动力扳手，右键自己驯服的成年飞行员猫，玩家悬挂在猫下方。
- 需要约 3.4 格净空（实际检测 3.35 格）、距离不超过 5 格；幼猫、别人的猫、已乘坐其他实体的猫、水中或正在被查看的猫不能起飞。
- 使用移动键并转动视角控制方向，空格上升、Ctrl 下降（可在控制设置中改键），潜行主动脱离。手上需继续持有扳手（主手或副手均可）。
- 不再给新飞行猫提供随身容器。旧背包实际有物品时，主人仍可潜行右键打开原来的 27 格界面；空手、普通物品、潜行持扳手均可。剪刀、扫描器等专用道具仍优先执行原功能。
- 旧背包保留普通整理/取物操作，不删物品、不强制清空；取空并关闭后不能再打开。是否有物品由服务端检查，避免联机客户端未同步背包 NBT 导致打不开。空背包潜行交互不会误切换坐下或起飞。
- 物流猫的容器、空手潜行物流界面不受影响。
- 玩家直接复用 Create 传动轮锁链的扳手悬挂姿态，支持左/右惯用手和副手扳手；不修改 Create 自己的锁链乘客名单。
- 载人时只显示一个包身环；非载人时隐藏。保留长方形躯干中心 X=0、Z=1 的对齐，随实时躯干姿态和缩放；下环及连接件已移除。
- 单环包住背部及两侧，外框 X=-3–3、Y=13–24.125，腹部底面 Y=20 到横杆内沿 Y=23 留 3 像素空间。背部和侧边内沿浅嵌 1/8 像素避免缝隙/共面闪烁；下横杆可供扳手开口勾住，不再延伸至 Y=30。
- 猫脚到玩家脚的承载高度由 2.35 调整为 2.5 格，配合单环横杆与实际扳手开口；不修改或拉伸玩家手臂。承载碰撞箱同步从 3.15 增至 3.3 格，起飞净空同步增加 0.15 格。
- 本地猫咪朝向立即跟随玩家视角，输入每 tick 发送。服务端只平滑速度大小，不再混合旧运动方向；其他玩家仍使用正常网络插值。
- 载人期间暂停猫的战斗、激光指令移动和自动行为。脱离后恢复原职业逻辑。

飞行 HUD 仅显示“飞行 N秒”或“滑翔”；仅净空不足显示“空间不足”，其他资格检查失败不误报净空问题。

## 属性公式

使用含套装、词条、饰品加成的有效属性，并应用全局/存档对应属性倍率：

- 满体力时长（秒）= 5 + 0.25 × max(0, 耐力)，最低 5 秒，无额外上限。换算成游戏 tick 后取整，以 long 储存/同步，兼容旧 int 消耗。
- 航速（格/秒）= 4 + 0.06 × 速度，无额外上限；删除旧 24 格/秒及最终运动向量 1.5 格/tick 双重限制。
- 原属性系统有效属性范围与配置倍率不变，不新增飞行限制；仍受世界建筑高度、碰撞和已加载区块约束。Ctrl 优先于向上看的俯仰，空格与 Ctrl 同按时垂直输入抵消；起飞自动抬升不会覆盖 Ctrl。

| 有效耐力 / 速度（倍率 1） | 满体力持续时间 | 航速 |
| --- | --- | --- |
| 0 | 5 秒 | 4 格/秒 |
| 50 | 17.5 秒 | 7 格/秒 |
| 100 | 30 秒 | 10 格/秒 |
| 150 | 42.5 秒 | 13 格/秒 |
| 1000 | 255 秒 | 64 格/秒 |

体力耗尽后保持挂载、自动转为下降滑翔；滑翔水平航速为正常的 65%，空格和向上看不能重新爬升，向下看或按 Ctrl 可以加快下降。落地后自动脱离。非战斗状态的地面休息每秒恢复 2 秒飞行体力；换扳手、重新挂载、保存/重载不会瞬间回满。旧版较大的体力消耗会先限制到新的容量，再逐渐恢复。

## 安全与持久化

- 服务端计算移动和消耗，客户端仅发送方向、视角与升降输入。输入仅接受实际猫主人兼乘客，有限值校验、频率限制、失联输入超时、非有限数校验和区块边界保护均在服务器执行。
- 临时承载实体是可保存的根实体，保存真实乘客猫及其已消耗体力，不复制或删除猫。未恢复玩家的孤立承载实体会自动释放猫。
- 换装、收纳、死亡、断线或失去扳手会清理承载关系；所有脱离均不再附加缓降状态，恢复正常重力，需自行注意高度。不会移除其他道具或模组已赋予的缓降效果。
- 飞行高度超过世界建筑上限 32 格时强制转入滑翔。
- 原猫饼完整 NBT 会保留体力消耗；地面休息才会恢复。

## 验证

隔离 GameTest 覆盖真实扳手挂载、普通服务端玩家乘坐、上下锚点、体力耗尽、强制下降、落地恢复、不重复回满、载具保存与孤立恢复、换装清理，以及 5 秒下限、高属性继续增长、long 时长、Ctrl 下降和双键抵消、急转与反向、旧消耗兼容、不附加/不移除缓降。accessories.14 新增真实交互测试：空背包不可开、不改 NBT，非空旧包支持空手/普通物品/潜行扳手，27 格内容与耐久保存重载，非主人拒绝，Shift 取物不丢不重，取空关闭后不可重开，空物流猫仍正常打开。

双端独立客户端探针验证真实 Create 类的 Mixin、左右手悬挂姿态与实际挂环几何烘焙。accessories.16 验证恰好四根横/竖杆、132 个单环轮廓采样点、腹下 3 像素净空内无多余几何，以及 450 项转向/姿态/缩放附着检查。资源加载完成后，读取实际 Create 扳手上下钳口和烘焙后的第三人称变换，结合原版悬挂姿态、玩家缩放和服务端承载高度，验证左右手 × 普通/纤细手臂模型的四种扳手开口均与横杆相交。不打开用户存档。

GameTest 和客户端探针都是独立测试源集，不随正式 JAR 发布；不代表已在完整整合包中完成画面与联机手感验收。
