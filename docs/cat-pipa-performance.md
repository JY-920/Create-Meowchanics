# 琵琶行（Forge / NeoForge）

- 编号：`laowu:pipa_performance`；优良、不可升级，与其他外观词条互斥。
- 智力属性+10、幸运属性+10；只增加当前有效属性，不改写基础属性、培养上限或遗传数据。不可升级的正面词条沿用七级图标样式，实际等级仍为1。
- 一只前爪扶琴颈并移动按弦位置，另一只持拨片往返扫弦；猫咪轻轻点头、晃动身体，尾巴随节奏移动。原版单根腿骨骼保留。
- 在地面闲暇时演奏，普通坐下也可演奏；移动、睡觉、哈气、猫饼姿态、骑乘（包括坐垫工作）、战斗、水中或离地时不播放，也不显示琴。
- 本次只制作外观动画，不附带音乐或声音，不改变 AI、碰撞箱、坐下状态、寻路或实体朝向。
- 原始毛色、融合方块材质、项圈和职业套装沿用现有路径。项圈和套装跟随本帧的猫咪骨骼；乐器按幼猫身体比例一起缩放。
- 调整棒可搜索「琵琶行」「拨弦」添加；过滤器与词条禁用配置自动包含新词条。自然生成、繁育继承和突变沿用统一规则；已有猫咪不会自动获得。

## Blockbench 工程

通过用户已配置的本机 Blockbench MCP 建模、创建动画、调整时间轴并截图检查。未修改 MCP 配置，也未覆盖街舞原工程。

- [完整猫咪、乐器和动画工程](blockbench/cat_pipa_performance.bbmodel)
- [Blockbench 内重建脚本](blockbench/build_pipa_performance.js)
- [前侧预览](blockbench/cat_pipa-front.png)、[另一侧拨弦预览](blockbench/cat_pipa-strum.png)
- 工程使用自由模型格式，以区分原猫咪贴图与独立的乐器贴图。
- 猫咪8根原骨骼，加琴与拨片2根骨骼；3.2秒循环，60帧/秒，共193个采样姿势；游戏维持原速。
- 乐器由41个低面数方块构成，包含阶梯状梨形琴身、琴颈、琴头、弦轴、品、4根弦、音孔、琴桥和拨片。

`tools/blockbench-mcp.mjs` 连接现有本地服务，供建模工具调用；不会随模组打包，也不增加运行依赖。`build_pipa_performance.js` 只能在已打开的专用 Blockbench 工程里运行。

`node tools/export-pipa-performance.mjs --write` 从实际保存的工程机械导出双端的精简动画、乐器几何和贴图；不把预览用原版猫咪贴图或完整工程重复打包进运行资产。不带 `--write` 时只验证源工程与导出资源一致。

## 实现与验证

- 动画只在客户端首次使用时读取一次，以共享不可变数据逐帧插值，不进行逐猫文件读取、网络同步或服务端运算。
- 自定义采样资源位于 `assets/laowu/cat_animation_clips/cat_pipa_performance.json`，避开 GeckoLib 自动扫描的 `animations/` 目录；导出工具与加载器保持一致，不添加 GeckoLib 依赖。
- 乐器几何复用现有 Blockbench 模型缓存及渲染器。猫咪和琴采用一致的坐标转换，避免左右反转与拨片脱手。
- 模型状态每次重新设置，不把演奏姿势或琴显示状态残留给其他猫；缺失或损坏的动画资源安全回退，不阻止进入世界。
- 新枚举追加在末尾，不改变旧词条序号；持久化仍使用固定编号。因编辑界面的词条数量变化，通信版本更新为 Forge 21 / NeoForge 14，联机双方需要使用匹配的新包。
- 双端构建成功。`tests/run-pipa-performance.ps1` 各校验961个姿势、399776个顶点；最大映射误差约0.000006像素，前爪接触误差约0.0023像素。
- Blockbench MCP 实际场景对193个采样姿势检查最低点，最小离地约0.01像素，无脚掌穿地。
- 缺失动画资源回退、十二种外观词条数值、项圈跟随、词条禁用、遗传与突变的回归检查通过。
- 已完成模型预览、构建和离线测试；尚未进行 Minecraft 实机或多人联机验收。
- 2026-09-11 已部署至 PCL 的 Forge 1.20.1 / NeoForge 1.21.1 模组开发实例，沿用现有 `2.1.3` 包文件名。部署前确认游戏退出，替换后 SHA-256 与构建产物一致；旧包保留为 `.disabled-before-pipa-20260911-155850988` 备份。未改动存档、配置或其他模组。
