# 猫咪收纳纸箱

物品 ID：`laowu:cat_storage_box`。猫咪养成创造物品栏，最多 9 只活体宠物猫，不堆叠；与既有装猫饼的猫袋、产哈气的航空箱独立。使用玩家提供的空箱/有猫箱 2D 贴图。配方为八个纸板围住中心的任意鱼。

## 操作

- 右键自己的宠物猫：收纳 1 只，跳过坐垫上的猫咪；要收纳它，先让它离开坐垫。
- 收纳、释放成功时在猫的位置产生白色云粒子；失败不播放。服务端发送给附近玩家。
- 蹲下右键自己的宠物猫：只收纳玩家周围 32 格球形范围内自己的宠物猫；先收符合条件的点击目标，再按距玩家远近收纳其他猫，最多 9 只，装满即停止。不再遍历整维度实体，不加载区块，不收其他玩家的猫。
- 单只与批量收纳均跳过坐垫上的猫，包括直接点击的猫。直接点击坐垫猫发起批量收纳时，仍会收纳周围其他符合条件的猫。普通坐在地面上的猫不属于坐垫猫，可以收纳。
- 右键方块顶面：按存入顺序释放 1 只。
- 蹲下右键方块顶面：释放全部；若某只没有安全位置，保留该只，继续尝试其他猫。

## 数据与安全

- 保存完整实体 NBT：身份 UUID、实体类型、主人、年龄、生命、名字、项圈队伍、属性、词条、材质、套装、随身物品。收纳不是死亡，不触发掉落/职业死亡属性惩罚。
- 清理原来的位置、速度、朝向、乘客、拴绳与临时激光指令。坐垫猫不进行数据转移或脱离坐垫；可收纳的拴绳猫按原版返还拴绳。
- 正在使用猫咪面板或物流菜单的猫暂不收纳，避免打开中的容器产生并发存取问题。释放保留原主人，不把猫转让给持箱者。
- 保留 UUID；释放前检查所有维度当前加载的实体，若同 UUID 已存在则保留箱内数据。不会为了检查身份去加载区块。
- 释放在点击地面附近 5×5、上下各 1 格内寻找支撑、无碰撞、无液体、世界边界内的位置，并避开其他猫。生成成功后才从箱内删除对应数据。
- 释放后仍保留原本被命令坐下的状态。收纳/释放在服务端执行，创造模式也是真实转移而不是复制。
- 主人离线或把纸箱转交别人不改变内部猫咪的归属。本物品没有额外的不死、防火或遗失恢复功能。

## 验证清单

双端构建与资源校验；空/有猫图标与 0–9 计数；收纳一只/批量收满；跨玩家归属隔离；存档重进后数据；属性、词条、材质、套装、背包、年龄、血量及项圈一致；坐垫/拴绳猫；有菜单打开的猫；单只/全部释放；受阻不丢失；相同 UUID 重复释放保护。游戏内交互与视觉仍需实测。
# 合成配方

- Forge / NeoForge：工作台四周 8 个 Create 纸板，中心任意鱼（minecraft:fishes），产出 1 个猫咪收纳纸箱。标准有序配方自动显示在 JEI 中。
