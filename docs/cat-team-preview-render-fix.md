# 归属预览头像渲染修复

- 问题：AFTER_PARTICLES 阶段往共享 BufferSource 写入颜色底板和玩家皮肤后，调用方只 endBatch(lines)。底板可在切换非固定缓冲时提交，但最后一张皮肤仍可能留在缓冲区，导致只显示队伍底色。
- 修复：CatTeamPreview 收集本次使用的底板、皮肤 RenderType，绘制结束时逐个 endBatch 提交。仅提交预览使用的类型，不全局清空其他渲染批次；同一主人皮肤去重。
- Forge 与 NeoForge 同步修复，保持头像高度、大小、颜色和头像帽子层不变。
- 验证时分别检查单只猫、多只同主人猫、不同主人猫；归属预览开关和带/不带光影均应显示头像。

## Forge 仍只显示底板的根因

- 补交批次后仍不可见：进一步核对实际 Camera 字节码，1.20.1 使用旋转后的 +Z 作为视线前方，1.21.1 则使用旋转后的 -Z。直接共用同一朝向逻辑会将 Forge 头像的正 Z 偏移放到不透明底板后面。
- Forge 的预览四元数局部增加绕 Y 轴 180°，使头像及帽子层朝观察者突出，同时修正左右镜像。不改变原相机四元数、位置、尺寸或高度。
- NeoForge 已具有正确的朝向约定，不额外翻转。
- CatTeamPreviewFrameRegression 覆盖 975 组偏航、俯仰、滚转组合，验证头像/帽子层在底板前面、左右和上下方向正确，且不修改共享相机状态；同一测试重现原朝向导致的遮挡。
