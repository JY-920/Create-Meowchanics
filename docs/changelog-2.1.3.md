# 2.1.3 更新日志

适用：Forge 1.20.1 / NeoForge 1.21.1。汇总从新增「街舞」词条至本次更新的内容。

## 新增内容

- 新增「街舞」外观词条：速度属性+10、耐力属性+10，静止时（包括坐下待命）播放二倍速托马斯回旋动画，支持项圈与套装同步运动。
- 新增「琵琶行」外观词条：闲暇时抱琴拨弦，身体轻轻晃动；智力属性+10、幸运属性+10，优良、不可升级。
- 新增激光笔轮盘：蹲下右键可开关宠物血条、团队显示，以及切换「仅指示或保护 / 主动攻击敌对生物」。
- 新增宠物猫血条：不显示野生猫；随血量由浅绿、浅黄到浅红平滑过渡，保留原像素边框与数字。

## 养成与配置优化

- 加强突变猫粮：随机继承5项属性，其余1项重新生成；突变率+40%，更容易产生优良、卓越的新词条。
- 调整突变猫粮配方：8份繁育猫粮＋1个毒马铃薯，加热搅拌获得8袋。
- 新增全局配置文件 `config/laowu-global.toml`：配置项设为 `-1` 时跟随存档设置；指定其他有效值时，强制覆盖并锁定对应的存档选项。
- 细化职业套装配置：可独立调整伤害系数、攻击间隔、防护数值和六维属性加成，支持恢复默认。
- 属性倍率与套装伤害系数配置上限提高至999999。
- 新增词条禁用名单及游戏内搜索管理，不移除已有猫咪的词条。
- 猫咪过滤器的当前属性筛选范围调整为0～300，培养上限筛选仍为0～100。

## 战斗调整

- 除钓鱼猫外，远程职业弹幕不再造成击退；近战和雷管猫临死自爆不受影响。
- 黄油猫支持任意方向冲刺，冲刺期间减伤50%；首次命中生物后改为继续冲刺0.3秒，期间每命中另一只生物再增加0.3秒。

## 问题修复

- 修复街舞时项圈停留在原地。
- 修复「上天猫」接受激光笔指令后悬空不动。
- 修复NeoForge「长毛护体」对机械手剪毛不生效。
- 修复创造物品栏搜索出现重复物品。
- 修复导航兼容代码导致的启动崩溃。
