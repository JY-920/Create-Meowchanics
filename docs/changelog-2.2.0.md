# 2.2.0 更新日志

适用：Minecraft 1.20.1 Forge / Minecraft 1.21.1 NeoForge。更新日期：2026-09-18。

本版汇总 2.1.4 之后的职业、饰品与领养更新，并整合后续暮色区块加载修复及特工猫烟雾修复。文件名与模组内部版本均为 **2.2.0**，不带 dev 后缀；同名旧本地发布包已备份，请按随包 SHA-256 区分。

## 猫咪饰品系统

- 开放猫咪独立的四格饰品槽，加入共 **36 件饰品**，涵盖通用、六维属性和职业专属效果，全部配齐正式像素图标。
- 为 13 个职业提供专属饰品玩法，包括激光追击、鱼钩拉近、飞行闪避、蓝色火焰、蜂蜜减速、物流二级药水、工程特殊弹药、医疗减伤、音乐速度加成、治疗烟雾、友军净化与蟑螂分裂。
- 增加连击、首击增伤、反伤、休息回血、受疗提升、主人近距离增伤、自动拾取与磁吸等通用搭配。
- 饰品分为普通、稀有、史诗三档；移除内置饰品制作配方，普通奖励由心愿领养箱提供，Boss 专属饰品不进入领养池。黄油块保留为黄油猫 Boss 专属掉落。
- 软木护胸、金基咪均为 **50 耐久、15 秒冷却**，成功触发消耗 1 点耐久，最后一次触发仍完整生效；两者互斥。
- 猫咪玩偶取消额外冷却；磨牙骨调整为史诗；钉刺项圈反弹实际近身受击伤害的 50%；加快磁铁吸取。
- 扩展音响为受音乐增幅的队友提供 **速度属性 +20**，不再是单独增加 10% 移动速度；不改写基础属性，多来源不叠加。
- 蟑螂分裂饰品生成两只继承主人及一半基础六维属性的幼猫，并继承有效攻击目标；不复制背包和饰品，避免连续分裂或物品复制。

## 六个新增职业

### 工程师猫

- 坐垫工作时摇动上方水平手摇曲柄，每点有效耐力提供 **128 SU** 应力容量。
- 战斗时架设炮台发射小齿轮；专属饰品可解锁大齿轮范围伤害与传动杆穿透。
- 攻速随速度属性变化，加入按智力调整架炮位置与重新部署的战斗策略。
- 套装保留生命、护甲和韧性加成，六维加成为幸运 +10；补充专属工作动作和炮台模型。

### 医疗猫

- 辅助职业，不主动攻击；靠近伤员后静止展开群体治愈圈，可治疗自己及空中的友方职业猫。
- 治疗速度和范围随智力成长，100 智力时每秒回复 **4 点生命**；分次治疗，多医疗来源不叠加。
- 坐在机械动力坐垫上时，可治疗自身 **3×3×3** 范围内受伤生物，包括玩家。
- 增加绿色轮廓、治愈圈和十字图标，站立施法与坐垫工作使用不同动作；接受治疗的目标仍可正常行动。
- 套装采用低生命、低防御、速度 +10 的辅助定位。

### 音乐猫

- 辅助职业，以琵琶或街舞动作提供团队攻速增幅，智力影响选位，优先照顾高输出队友或更多远程猫。
- 0／100 速度分别提供 5%／25% 攻速加成，继续随有效速度成长；多只音乐猫仅取最强效果。
- 调整增幅范围，并为受增幅目标显示紫色轮廓、范围提示和攻速提升图标；原琵琶行、街舞词条不再单独附带紫框。
- 自动按顺序循环播放自身 **9 格物品栏**中的唱片，不消耗唱片，不要求坐垫；不新增 27 格唱片容器。
- 套装采用低生命、低防御、速度 +10 的辅助定位。

### 特工猫

- 低生命、低防御、高伤害的近战职业，背后直接攻击必定暴击，高智力时尝试绕后。
- 被敌人锁定且附近有非辅助友方猫时，立即释放烟雾掩护撤离，不受智力限制，冷却 10 秒；独自作战或身边仅有辅助队友时不会触发。
- 清除铁傀儡等生物缓存的报复目标、追击和愤怒记录，隐蔽期拦截重新选敌；烟雾消散后不恢复旧仇恨，但新的攻击仍可正常再次激怒敌人。
- 增加直拳、连续拳和旋转踢表现，使用站立骨架；多段动作不额外增加伤害次数。
- 坐垫警戒为范围内敌对生物显示红色外框：100 智力对应 64 格，最高 **128 格**，仅扫描已加载目标。
- 普通及治疗烟雾采用营火风格浓烟：初始粒子约为原来的四倍，粒子放大、主体不透明度提高至 100%，保留柔边及末尾淡出；不再显示烈焰弹投掷物，无需其他猫咪特效模组。

### 潜水员猫

- 支持手持机械动力扳手骑乘，水下速度比同属性飞行员更快，速度和耐力共同影响潜航表现。
- 支持水中三维操控、空格上浮与 Ctrl 下潜；耐力耗尽后减速并尝试上浮，陆地骑乘速度降低 80%。
- 近距离锥形喷水可同时攻击多个目标，成功命中后洗去敌方正面药水效果；专属饰品可额外净化友方猫的负面效果。
- 增加花状水花、气泡、溅水音效和水下载人伸肢动作。

### 蟑螂猫

- 附近每只其他友方蟑螂猫提供生命、战斗力属性各 **+6**，不增加耐力，不改变遗传基础值。
- 追击时展翅冲刺，受击时展翅，增加展翅跳扑攻击。
- 空闲时有概率对 **9×9×9** 范围内耕地上的一株有效作物施加骨粉催熟；概率随生命属性提高，不消耗物品，不清除掉落物。

## 原有职业与骑乘调整

- 飞行员猫可通过机械动力扳手载人飞行，支持 Ctrl 下降、耐力耗尽后滑翔及落地休息恢复。
- 调整飞行生存能力、载人朝向响应、挂环对齐、伸肢动作及进入／退出衔接；简化飞行提示和“空间不足”提示。
- 取消载人飞行原有的固定时长和航速硬上限，继续由属性驱动；仍遵守统一有效属性和服务器运行规则。
- 飞行员不再提供新的 27 格随身背包；保留已有非空旧背包的取回兼容，不清空旧物品。
- 物流猫按不同目标 1 秒、同一目标 5 秒的节奏提供支援；辅助职业移动更快且不主动攻击。
- 无职业猫加入较低的基础伤害公式；调整部分职业默认平衡，**钓鱼猫原有默认数值不改**。旧存档自定义参数按既有迁移规则保留，不一刀切覆盖。

## 心愿领养箱

- 新增以符合条件的猫饼兑换饰品的心愿领养箱，支持 **NOW 当前基础属性**或 **MAX 属性上限**判定。
- 使用统一六维图标和像素数字；无需满足的属性黯淡显示。普通／稀有／史诗奖励分别要求 2／3／4 项条件。
- 满足条件即可交易，未锁定时交易成功后刷新条件与奖励；锁定时保留当前交易。
- 模型白色立牌实时展示奖励饰品图标；调整 GUI 预览、物品蒙层位置，修正两种领养箱底板闪烁。
- 制作完成的心愿箱立即附带交易信息；采掘、携带、重新放置保留奖励、条件和锁定状态，不能通过反复挖放刷新。
- Boss 专属奖励与领养池分离，保留旧交易和旧箱子的安全迁移。

## 收纳、筛选与配方

- 猫袋可右键直接收纳猫咪及活体猫饼，保留主人、属性、词条、职业、装备和物品栏，作为纸棍收纳流程的替代入口。
- 猫袋配方调整为顶中线、中排三块皮革、底中黄铜锭。
- 猫咪过滤器右键心愿箱，可先清空旧规则再导入当前交易的 NOW／MAX 范围；复制的是当前交易，不自动追踪之后的刷新。
- 补全工程师、医疗、音乐、特工、潜水员、蟑螂六套机械动力序列组装配方。
- 15 个半成品统一接入原生序列组装进度与贴图，保持旧 ID；隐藏中间件不会造成序列步骤缺失。

## 表现、说明与联机修复

- 修复与暮色森林天气钩子交互时的区块加载自等待：将猫咪完整初始化推迟到正常实体 tick，避免“能移动但无法交互”的服务端锁死调用链。
- 套装默认说明统一为职业类型、战斗能力和工作能力；Ctrl 查看详细规则，Shift 查看数值预览，移除重复或无意义说明。
- 修正饰品百分号渲染、名称、互斥说明和提示顺序，保留中文与英文支持。
- 修复音乐猫无对应词条时琵琶模型不显示、唱片播放同步，以及医疗／音乐动作、图标和范围提示问题。
- 修正坐垫医疗动作偏移、特工攻击坐姿、骑乘与蟑螂动作衔接，以及世界实体和界面预览之间的临时状态干扰。
- 修复服务器上词条调整棒后半段词条无法添加的问题，相关操作由服务端校验。
- 修复 NeoForge 部分物品栏保存槽位、蟑螂死亡分裂重复猫饼和幼猫不继承攻击目标的问题。

## KubeJS 与整合包支持

- 提供可选 CatAccessoryEvents / CatAccessoryApi：装备、卸下、定时、伤害、治疗、弹幕和自爆等事件，以及持久状态、冷却、充能、动态属性和耐久操作。
- 保留 API v1–v3、schema 1 和旧物品 ID，增加 supportsApi 兼容声明与正常构建中的接口检查。
- 独立交付 AI 友好的开发文档、新物品注册示例，以及 36 件原饰品的可替换脚本：**7 件事件脚本＋29 件声明式调用本体机制**，不是 36 件纯 JavaScript 重写。
- 替换脚本通过兼容检查且注册完成后才接管效果；本体 JAR 不夹带玩家脚本、示例、测试世界或探针，不覆盖已有 kubejs。
- 不新增强制 KubeJS／Curios 依赖；不装脚本仍可使用内置饰品。同兼容线内保留接口即可继续使用现有 SDK，跨 Minecraft／KubeJS 大版本仍需复测。

- 2026-09-18 刷新包含上述烟雾及加载修复，不代表修复了此前所有遗留问题；未另改职业伤害或饰品治疗数值。
