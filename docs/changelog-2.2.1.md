# 2.2.1 更新日志

适用：Minecraft 1.20.1 Forge / Minecraft 1.21.1 NeoForge。
发布日期：2026-09-19。文件名和模组内部版本均为 2.2.1，无 dev 后缀。
以下汇总上一次公开 2.2.0 打包后已经实装的改动。

## 音乐猫

- 兼容 NetMusic 1.5.2 的网络唱片，可与原版唱片混放在猫咪原有 9 格物品栏内，按槽位顺序循环播放。
- 音源跟随猫咪移动，不消耗唱片，不要求坐垫，也不增加额外背包。
- 实际播放时在头顶显示音符；猫咪静止时表演琵琶行或街舞，移动时退出唱片表演，停止移动后恢复。移动不会中断音乐。
- 保留琵琶模型；唱片表演与战斗攻速增幅分离，不因播放唱片额外触发增益。
- 取消头顶歌词框、曲名框及对应后台歌词请求。开始网络歌曲时原有游戏 HUD 曲名提示保留。
- 切歌、取出唱片、卸下音乐套装、离开世界或播放失败后清理该猫音源和表现，不影响其他猫或普通唱片机。
- NetMusic 为可选兼容；不安装时仍可播放原版唱片。网络歌曲受 NetMusic 地址有效性、授权及客户端网络影响；本地音频文件需在每个收听客户端存在。

## 驯养猫死亡与属性配置

- 已驯养猫即使没有职业，死亡时也能变成可还原的猫饼，成年猫和幼猫均适用。
- 在世界设置的“死亡设置”中选择：不产生猫饼、掉落猫饼物品（默认）、转变为猫饼生物。
- 后两种模式保留主人、名称、外观、年龄、词条、属性上限、9 格物品栏及饰品，不重复掉落随身物品；不产生猫饼时，随身物品按原有掉落规则正常掉落。
- 新增死亡属性扣除开关和扣除点数配置，可在世界设置中调整；默认随机一项基础属性扣除 20 点，最低为 0。
- 关闭扣除或设为 0 时不扣属性；不影响其他基础属性、属性上限或普通捕捉。服务端配置生效，支持全局覆盖。
- 只有后两种死亡模式显示属性扣除开关与点数；切换到不产生猫饼不会清空已设置的扣除选项。
- 保留图腾、掉落规则和蟑螂分裂的原有处理。

## 词条 KubeJS 接入

- 新增 CatTraitApi v1 / schema 1 与 CatTraitEvents，可通过服务端数据及脚本定义自定义猫咪词条、等级、六维加成和事件效果。
- 自定义词条与原有词条共享四个位置，并接入词条面板、调整棒、过滤器和生成黑名单；名称和描述由服务端同步。
- 支持存档与重载；定义缺失时保留词条 ID、等级和脚本状态，避免因脚本暂时移除而清空猫咪数据。
- 保持原有 82 个内置词条 ID、36 个饰品 ID 和饰品 API v1–v3 的兼容契约。

## 更新说明

- 客户端与服务端请同时更新。按加载器选择一个 JAR，不能混装 Forge 与 NeoForge 包。
- 更新前备份存档，并移除旧版老吴学 JAR，避免重复加载。
- 不会自动覆盖玩家配置或 KubeJS 脚本。示例脚本、SDK、测试探针和测试世界不包含在运行 JAR 内。
