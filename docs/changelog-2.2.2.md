# 2.2.2 更新日志

适用：Minecraft 1.20.1 Forge / Minecraft 1.21.1 NeoForge。
打包日期：2026-10-03。文件名和包内版本均为 2.2.2，无 dev 后缀。
以下汇总正式 2.2.1（2026-09-19）之后的累计改动；不重复列入 2.2.1 已发布的网络唱片兼容、死亡配置及词条 KubeJS 接入。

## 猫机器与猫机壳

- 新增猫机壳、猫冲压机、猫搅拌器、猫工作盆和猫置物台。猫加工机器支持正放、侧放、倒放等六向布局，沿用 Create 同类配方、应力、过滤、热量条件、物品／流体处理与输出队列，并补齐 JEI 催化物显示。
- 冲压机与搅拌器自带两个相对的应力接口，接口内凹一模型像素；修正接口方向、传动杆、动态部件和物品栏图标。搅拌桨通电待机时旋转，加工时伸出，冲压动作随实际加工进度播放。
- 机器加工端与同向盆／台相距两格，中间留一格空间。支持从盆／台工作面放机器，也支持从机器工作端反向放盆／台；阻挡、位置占用和权限不允许时不消耗物品。搅拌器配工作盆，冲压机可配工作盆或置物台。
- 普通右键置物台优先存取材料，手持机器也走存放流程；潜行右键绕过容器交互进行放置。扳手旋转机器，盆／台非工作面也可旋转；保留过滤／出料嘴操作及潜行扳手快速拆除。
- 修复侧放、倒放工作盆的闭合外壁误收掉落物；修复多方向台面交互、加工目标判定、动画同步和出料相关问题。旋转保留库存和液体。
- 补齐四种机器的生存配方：机壳材料替换为猫机壳；工作盆中间一行的两个安山合金替换为猫锭。猫机壳由去皮原木／木头与猫锭应用制作，支持手动和动力机械手。
- 猫机壳、猫冲压机、猫搅拌器、猫置物台支持木斧或木镐采集；猫工作盆支持木镐采集。
- 猫机壳可包覆传动杆、大小齿轮及 Create 传送带区段，接入新绘制的轴口、分隔面和连接纹理。传送带不再作为独立新品入口；保留旧 `cat_belt` ID 和连接器行为以兼容存档，旧连接器创建普通传送带。
- “哈基工作盆”显示名称改为“猫工作盆”，注册 ID `haji_basin` 保持不变。

## 巨猫坐骑

- 新增史诗猫咪饰品“蘑菇点心”。装备于驯服成年猫后巨大化，主人空手右键骑乘，使用方向键、疾跑及空格控制。生命属性 100 对应基准体型，体型随有效生命属性的平方根增长；受伤不会缩小。
- 保留原猫的花色、基因、职业、词条、主人、物品栏与饰品。职业套装在巨猫头部显示；骑乘期间停止攻击，支持型职业效果仍可生效。
- 新增移动、奔跑、跳跃、落地回弹和侧躺待命过渡，使用身体／腿部拉伸回弹降低跑步上下起伏。静止时脚保持落地；调整尾巴粗细、长度、衔接与躺姿接地。
- 主人潜行空手右键切换侧躺待命。躺下时身体不跟随观察目标转动，头部可在有限角度内观察玩家和周围生物；骑乘起身从首帧开始平滑跟随玩家方向。
- 玩家模型跟随真实猫背动画起伏，保留稳定物理座位；第一人称采用小幅平滑起伏。修复飞行员／潜水员巨大化后的趴姿残留、骑手朝向偏移和短按空格跳跃被吞的问题。

## 大猫猫 Boss

- 新增召唤物“神秘蘑菇”：右键未驯服猫，经过与黄油猫同类的召唤过程变为大猫猫 Boss，继承花色和名称。配方为毒马铃薯、任意蘑菇和 500 mB 哈气无热搅拌；召唤物描述提示会令未驯服猫变得具有攻击性。
- Boss 为 800 生命，免疫击退，普通追逐速度提高。普通攻击改为头部／鼻部接触咬伤，不播放主动近战动作或哈气声；咬伤带小击退，并可命中矮小猫咪。
- 特殊攻击交替使用侧躺连续翻滚和蓄力跳跃坐砸。翻滚侧面对准目标，可缓慢改变推进方向，最后顺势站起；坐砸命中附加缓慢 I、虚弱 I 各 5 秒。特殊攻击保留后摇，不破坏地形，贴近目标时也不会永远只追逐。
- 修正翻滚方向、起身额外转动、坐砸头部与四肢姿态、提前落地及中断过渡。旧存档的原默认 550 生命／旧移速升级时保留生命比例。
- 修复普通索敌追逐的突然左右急拐和整圈回转：近身接近与路径移动使用同一平滑转向控制，大幅变向时先转身，保留原寻路、碰撞、台阶与避坑规则。
- 死亡掉落 1～3 件高级养成道具，另有独立 25% 概率掉落“蘑菇点心”。该饰品不从心愿领养箱刷新；召唤物和饰品使用新提供的图标，显示名称分别为神秘蘑菇／蘑菇点心，原 ID 不变。

## 其他修复与兼容

- 普通领养箱和心愿领养箱按 3×3 输入格展示最多九只猫饼，保留各自花色和体型，限制超大模型显示尺寸。
- 优化飞行员尾根朝上、尾端快速旋转的旋翼效果；完善潜水员双手姿态、骑手与披风跟随，修复耐力耗尽上浮时在水面反复弹跳和循环陆地提示。
- 修复 Forge 正式运行环境中的注入映射问题导致的启动失败。
- 音乐播放增加隐私安全的失败诊断日志。此前反馈的网络唱片无声未在原实例复现，不能视为已确认修复。
- 保留既有物品 ID、饰品 API v1–v3／schema 1、词条 API v1／schema 1 兼容契约；运行包不携带示例脚本、SDK、测试探针或测试世界，不覆盖玩家 KubeJS、配置或存档。
