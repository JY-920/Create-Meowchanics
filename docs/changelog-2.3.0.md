# 2.3.0 更新日志

适用：Minecraft 1.20.1 Forge / Minecraft 1.21.1 NeoForge。以下汇总 2.2.2 之后的主要更新；两端使用相同玩法和数据规则。后续兼容修复与无机械动力猫面团路线见 [2.3.1 更新日志](changelog-2.3.1.md)。

## 拳击猫与猫咪养成

- 新增博古架和拳击猫 Boss。博古架会吸引附近未驯服的猫；玩家连续抚摸架上的猫三次、听完哈气后，在猫附近召唤拳击猫。只有野生猫可参与召唤。Boss 有血条、刷怪蛋、近战格斗动作和高级养成材料掉落。
- 拳击猫遵循其他猫咪 Boss 的和平难度规则：和平模式下抚摸架上的猫仍可哈气，但不会转换成 Boss；最后一段哈气期间切换和平会取消召唤并保留原猫。已生成的拳击猫在切换和平后消失，不恢复成普通猫。
- 修复拳击猫始终使用固定橘猫贴图的问题，支持继承来源猫咪的全部原版花色和混合部位材质；补齐格斗模型暴露的肢体、拳头等贴图区域，避免原版材质的透明缺口。
- 拳击猫另有独立 25% 概率掉落史诗饰品“拳击手套”，使用玩家提供的 16×16 图标。手套现改为让**装备近战职业套装的猫咪，其直接近战伤害提高 30%**；不再增加固定攻击属性，也不再触发第三击上勾拳。无套装、远程和辅助职业不会得到这项加成；辅助职业原有的禁攻规则不变。
- 保留既有饰品 ID 和 `boxing_uppercut` 数据机制供自定义饰品脚本使用；仅内置拳击手套的效果定义改变。

## 猫咪编辑与自动化机器

以下五种机器需要安装机械动力；未安装机械动力时不启用。两端功能一致。

### 猫编辑台

- 将自己驯服的猫安置在编辑台同层、水平相邻的机械动力坐垫上，右键编辑台即可编辑这只猫。
- **词条编辑**：展示最多四个词条的稀有度、等级和悬浮说明，支持拆成瓶装词条或装入瓶装词条，保留原等级；词条按顺序紧密排列，重复、冲突或满槽时不能安装。瓶中液体按四档稀有度显示不同颜色。
- 拆卸没有代价；安装优良词条有 50% 概率损失某一随机基础属性的 10–50 点，安装卓越词条有 50% 概率损失某一随机基础属性的 10–50 点、10% 概率损失某一随机属性上限的 10–20 点，两种损失不会同时发生，其余概率不损失。另两档稀有度安装无损失。悬浮安装按钮时，优良词条隐藏 NOW，卓越词条隐藏 NOW/MAX，以“???”提示风险。
- **外观编辑**：支持整体和各个部位分别选择原版猫咪材质，也可放入方块样本使用该方块材质。右侧模型实时预览，确认后才写入猫咪；使用方块样本的实际修改消耗对应材料。“还原”取消未确认修改，不清除此前保存的外观。界面下方保留玩家物品栏，关闭后归还临时槽中的物品。

### 猫咪部署台

- 用哈气将猫饼还原成猫咪，适合猫咪储运后的自动部署。每次成功部署消耗一个猫饼和 **250 mB 哈气**；机器储液容量为 **4000 mB**，支持桶和流体管道供液。
- 手持猫饼右键放入，也支持顶面掉落物和物品自动化；一次暂存一个猫饼，空手右键可取回尚未部署的猫饼。还原保留主人、职业、属性、词条、背包和饰品等猫咪数据。
- 哈气不足或生成空间受阻时保留材料并自动重试；拆除后待部署猫饼和哈气随机器物品保存。

### 猫咪弹射部署台

- 在普通部署台的还原功能上增加定点弹射：手持机器时蹲下右键目标方块选点，蹲下左键取消，再正常放置机器。
- 机器与落点须沿同一 X 或 Z 轴，距离遵守机械动力的弹射距离配置（默认 32 格）。供给猫饼和哈气后，猫咪沿活体弹道弹射到目标，无需额外旋转动力。
- 弹射是真实运动，不是传送，不穿墙；目标无效、落点受阻或目标区块未加载时不扣材料。目标框便于检查落点，挖起机器保留相对目标偏移，换位置放置时落点随之平移。

### 自动激光标记器

- 接入旋转动力后展开，在 **24 格球形范围**内自动搜寻、转向并锁定无遮挡的目标，动态显示红色标记光线；停转或超载时收回。支持六向放置和扳手旋转。
- 将驯服的机械猫安置在距离机器 **5 格内**的机械动力坐垫上，猫便会原地向已锁定目标射击；伤害、攻速和饰品效果沿用猫咪原有职业规则。多台机器不会为同一只猫叠加射速。
- 默认按敌对目标规则工作；背面安装生物过滤器后，可按生物种类、成年状态、驯服状态和血量百分比筛选目标。筛选不会绕过友方保护或方块遮挡。

### 生物转信器

- 将附近符合条件的生物数量转成红石信号。右键配置 **1–16 格球形检测半径**、数量条件和输出模式；不统计玩家。顶部使用机械动力原生过滤槽交互，装入生物过滤器后按其规则统计。
- **阈值模式**：数量达到上限时开启 15 级信号，降至下限时关闭；两者之间保持原状态，避免数量在边界附近变化时频繁闪烁。
- **计量模式**：下限对应 0 级、上限对应 15 级，中间按数量比例输出并向下取整，超出范围时保持 0 或 15 级；支持反转输出，两种模式的火把悬浮说明随模式切换。
- 四面红色区域随输出信号亮起。蹲下右键可持续显示检测范围，再次蹲下右键、经过三分钟或拆除方块后关闭。

配套生物过滤器采用两行配置：第一行搜索生物名字或 ID、选入／反向选入／删除；第二行为当前生物单独设置属性满足方式、成年状态、驯服状态和血量百分比（如 `<=50`）。不同生物可保存不同属性条件；同一过滤器可用于自动激光标记器和生物转信器。

## 可选机械动力与生存配方

- 机械动力不再是模组强前置。未安装时保留猫咪、套装、属性与词条、饰品、Boss、骑乘、扫描器、三档繁育箱、两种领养箱、猫收纳纸箱及独立生存配方；机械动力机器、过滤器和相关工作能力不启用。安装机械动力时沿用完整工业玩法。迁移旧存档前请备份，尤其是曾放置机械动力机器的世界。详见[可选机械动力说明](optional-create.md)。
- 安装机械动力时新增猫编辑台、猫咪部署台、猫咪弹射部署台、自动激光标记器和生物转信器的工作台配方；未安装时这五张配方不加载。
- 猫咪部署台配方改为从上到下“铁栅栏、猫机壳”；弹射部署台改为“纸板、铁栅栏、猫机壳”。其余新增配方：猫编辑台为上方空白蓝图、下方一排三枚猫锭；激光标记器为激光笔、猫块、齿轮竖排；生物转信器为电子管、猫机壳、红石比较器竖排。

## 生物过滤器修复

- 修复搜索“猪”后点击“输入目标”或“输入反选目标”会误加入疣猪兽的问题。完整生物名称、完整 ID 或不带命名空间的 ID 优先于部分匹配；已有列表中的部分匹配不会挤掉精确结果。输入框与实际加入的目标保持一致，仍可用滚轮或方向键主动选择其他搜索结果。Forge 与 NeoForge 同步修复。
- 修复选过目标后重新输入相同名称可能不刷新搜索结果的问题。

## 兼容说明

- 修复 Forge 正式发布包启动崩溃：补齐独立猫咪骑乘姿势和可选机械动力掉落表处理的 Mixin 方法映射，兼容安装／未安装机械动力两种环境；不再因注入目标找不到而连带导致其他模组加载失败。
- 现有存档物品 ID 不变；猫咪饰品 API v1–v3／schema 1 和词条 API v1／schema 1 保持兼容。客户端和服务端需使用匹配加载器的同版本 JAR。
- 本地构建或部署不表示已上传到 CurseForge 等发布平台，也不自动修改玩家存档、配置或 KubeJS 脚本。
