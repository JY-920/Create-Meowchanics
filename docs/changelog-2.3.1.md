# 2.3.1 更新日志

适用：Minecraft 1.20.1 Forge／Minecraft 1.21.1 NeoForge。此版本在 2.3.0 基础上补齐无机械动力时的猫饼获取与还原，并修复创造搜索和新鲜动画兼容问题。

## 无机械动力的猫饼获取与还原

- 新增无序合成：**1 个小麦＋1 份猫毛 → 1 个猫面团**。
- 猫面团可在**原版熔炉**中烧制 **10 秒**，得到 **1 个随机花色猫饼**，生成正常的外观、六维属性和词条数据。结果只在烧制成功时随机；输出槽已满时不会重新随机或继续消耗面团。
- 手持猫饼**蹲下右键方块**，可在邻接空间还原猫咪，保留主人、姓名、花色、属性、词条、套装和物品栏。还原受阻、越界或无操作权限时不消耗猫饼；创造模式还原不消耗。
- 未安装机械动力时，猫饼说明改为“**蹲下右键方块还原猫咪**”。普通右键蓄力投掷、铲子拍击／拾取、铁砧和猫收纳袋交互不变。
- 以上新配方与右键还原仅在**未安装机械动力**时启用；安装机械动力时沿用原加工、鼓风机和部署台路线。

## JEI 配方预览

- 修复猫饼配方结果没有外观数据时的异常材质映射，默认使用**橘猫材质**。
- JEI 的默认预览不改变熔炉实际产出的随机花色，也不会覆盖已经保存的猫咪材质。

## 新鲜动画兼容

- 修复使用 Fresh Animations 时普通猫咪眼睛消失的问题，接入资源包的眼睛部件与猫咪动画。
- 混合花色和左右眼使用不同材质时，保留资源包额外使用的眼睛贴图区域，按左右眼分别合成。
- 普通猫保留资源包动画；哈气、猫饼、套装等需要本模组专用模型的表现优先使用自身模型与匹配材质，解除后恢复资源包模型。
- 带有街舞或琵琶词条的猫，在未演出时不再永久替换资源包模型；圆头表现按战斗状态生效。
- 支持资源包重载和启用／停用切换，不新增 EMF／ETF 强前置。实测组合为 Fresh Animations 1.10.4、EMF 3.3.11、ETF 7.2.5；猫咪 Boss 仍使用自身模型。

## 启动与搜索兼容

- 修复整合包修改创造栏滚动字段后触发的启动崩溃，不再依赖该内部字段。
- 在可选拼音搜索的查询出口处理本模组重复结果，保留合法的不同猫咪数据变体和原顺序，不改变其他模组物品或非物品查询结果。
- 补齐 Forge 猫面团熔炉处理的正式运行方法映射，避免仅在开发环境正常、成品包启动失败。

## 更新说明

物品 ID、猫咪存档数据、饰品 API v1–v3／schema 1 和词条 API v1／schema 1 保持兼容。客户端与服务端请使用对应加载器的同版本 JAR；更新前建议备份存档。2.3.0 的拳击猫、机器与配方介绍见 [2.3.0 更新日志](changelog-2.3.0.md)。
