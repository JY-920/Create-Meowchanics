# 猫画开发版更新内容

内部版本：2.3.2-dev.painting.1。适用 Minecraft 1.20.1 Forge 和 Minecraft 1.21.1 NeoForge；公开版本号仍为 2.3.2，不改写已发布的更新历史。

## 新增猫画编辑桌

- 沿用机械动力蓝图桌模型，使用 Create 风格的界面和原生控件。
- 从本地导入 PNG、JPG、JPEG，选择时显示预览，确认印制后才上传。
- 支持原生高清和每格 16 像素两种模式，宽、高分别可设为 1 至 8 格。
- 支持宽度保留和高度保留，等比居中裁剪或留边，不拉伸图片。

## 新增可挂墙猫画

- 使用猫机壳样式画框，支持四向挂墙、完整支撑与碰撞检查。
- 图片随世界保存，由服务器按需同步给其他玩家；删除本地原图后仍可显示。
- 已印制猫画支持拆下、重新放置和重印，失败时保留原画。
- 编辑桌仅在安装机械动力时注册；猫画核心功能不依赖机械动力。

本开发版暂从创造物品栏获取新增物品，未新增配方。导入目录、图片限制及世界备份方法见 [猫画编辑桌使用说明](cat-painting.md)。
