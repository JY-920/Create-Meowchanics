# 猫画开发版 painting.6

适用：Minecraft 1.20.1 Forge / Minecraft 1.21.1 NeoForge。公开版本号仍为 2.3.2。

- 新增 12 幅内置猫咪像素画，包含 1×1、2×1、2×2 和 4×4 格尺寸，沿用猫机壳画框。
- 普通猫画直接右键墙面即可随机放置，仅从能完整容纳且不重叠的画作中选择。
- 内置画在存档中固定保存所选图片，拆下后返还普通猫画，可重新放置随机换图。
- 内置画随模组提供，不需编辑桌、不需上传图片，也不占服务器图片库容量；无机械动力时同样可用。
- 编辑桌印制的自定义图片继续保持原图和原尺寸，不会变成随机图片。
- 同步中英文物品提示；客户端和服务端需同时更新对应加载器版本。

尺寸和使用方法见 [猫画说明](cat-painting.md)。
