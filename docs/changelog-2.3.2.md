# 2.3.2 更新日志

适用：Minecraft 1.20.1 Forge／Minecraft 1.21.1 NeoForge。本次更新修复猫咪置物台的动力臂接入，并补齐双端驯服交互与 JEI 配方扫描的兼容处理。

## 猫咪置物台与动力臂

- 修复动力臂无法将猫咪置物台选为存入或取出目标的问题，接入机械动力原生的存取接口。
- 支持六个放置朝向，抓取位置与夹爪方向跟随置物台工作面。
- 修复目标选定后再用扳手旋转置物台时，动力臂仍沿用旧抓取角度的问题，无需重新选择目标。
- 存取模式与目标配置支持保存重载；原有压片机、机械手和注液器加工功能保留。

## 猫咪驯服交互

- 修复带有“只贴不生”词条的野生猫咪无法用鱼驯服的问题，不再把原版鱼类驯服交互当作繁育罐操作拦截。
- 繁育罐仍受不可繁育条件限制；“厌食”词条仍会拒绝食物，不因本次修复解除限制。
- Forge 与 NeoForge 同步上述处理。

## JEI 兼容

- 扫描猫饼相关配方时，跳过不支持读取结果物品的特殊展示配方，避免因此中断本模组的 JEI 初始化。
- 对单张异常配方增加隔离处理，避免一个配方的运行时异常阻断其余配方扫描。
- Forge 与 NeoForge 同步修复，NeoForge 同时兼容直接配方和 RecipeHolder 包装的配方。

## 更新说明

未安装机械动力时仍可使用猫咪养成内容；动力臂接入仅在安装机械动力时启用。现有物品 ID、猫咪存档数据、饰品 API v1–v3／schema 1 和词条 API v1／schema 1 保持兼容。

客户端与服务端请使用对应加载器的同版本 JAR，更新前建议备份存档。此前猫面团、猫饼还原、新鲜动画与搜索兼容更新见 [2.3.1 更新日志](changelog-2.3.1.md)。
