# 2.3.3 更新日志

2026-11-12 · Minecraft 1.20.1 Forge / Minecraft 1.21.1 NeoForge

本次为 2.3.2 之后的小版本更新，汇总猫画系列开发内容、钓鱼宝藏修复及相关兼容改进。双端版本统一为 **2.3.3**，不带开发版后缀。

## 新增猫画与猫画编辑桌

- 新增可挂墙的猫画：空白猫画右键墙面，随机放置 12 幅内置猫咪像素画之一，仅选择墙面能容纳且不会重叠的画作。
- 新增猫画编辑桌，采用新版“茂华”模型，支持水平朝向和非完整方块外形。
- 从游戏目录的 `cat_paintings/imports` 选择 PNG、JPG、JPEG 图片，预览后印制到猫画上。
- 支持原生高清与像素模式；宽、高分别可设为 1～8 格。像素模式每格 16 像素，原生模式最长边最多 2048 像素。
- 支持宽度保留、高度保留，等比居中裁剪或留边，不拉伸图片。
- 界面沿用机械动力风格控件，以原版制图台纸张展示预览；底栏左侧放入猫画，右侧取出成品，箭头显示印制进度。
- 修复预览长时间停留在生成中、重复弹窗、背景拼接及控件对齐问题；空预览使用纯色填充，清理玩家物品栏上方多余提示。
- 挂墙画使用猫机壳风格边框，修正大尺寸画框的纹理衔接。
- 自定义图片随世界保存并向联机玩家同步；拆下、重放保留图片和尺寸。迁移世界时请同时保留世界中的 `laowu/cat_paintings` 目录。
- 猫画物品描述：右键放置随机猫咪像素画，也可在猫画编辑桌中印制自己的图片。

### 命名专属画：奶油与小米

- 在铁砧将猫画命名为“奶油”或“小米”，即可放置对应高清照片；也支持“《奶油》”与“《小米》”。
- 命名物品具有附魔光效，两张专属画不会出现在随机画池。
- 奶油占 3×2 格，小米占 3×4 格；修正奶油上下留白，使照片铺满画框。
- 命名画拆下、重新放置及保存重载保留身份；兼容此前开发版的挂画尺寸与数据。

### 新增配方

猫画编辑桌（纸板为机械动力纸板）：

```text
纸板  纸板  纸板
      铁锭
      铁锭
```

猫画：

```text
猫毛  猫毛  猫毛
猫毛  纸板  猫毛
猫毛  猫毛  猫毛
```

以上配方仅在安装机械动力时加载。未安装机械动力时，猫画核心功能、内置随机画和命名画仍可用，但本版未新增无机械动力的猫画配方；编辑桌仅在安装机械动力时启用。

## 钓鱼套装修复

- 修复钓鱼猫无法获得附魔书等原版宝藏的问题：此前向战利品表传入猫实体，无法通过宝藏分支的鱼钩条件；现在使用不生成到世界中的专用鱼钩上下文。
- 保留猫咪现有水域工作条件、幸运值换算及数据包掉落表，不额外生成真实鱼钩实体。
- 默认属性倍率为 1、原版掉落表未被修改时，每次成功钓获的概率如下；附魔书已包含在宝藏概率中：

| 有效幸运值 | 宝藏 | 附魔书 |
| --- | --- | --- |
| 0 | 5.00% | 0.83% |
| 50 | 8.16% | 1.36% |
| 100 | 11.34% | 1.89% |

幸运值提高获得宝藏的概率，不保证获得宝藏，也不直接提高附魔书的附魔等级。

## 机械与材质包兼容

- 修复猫冲压机不能加工传送带上材料的问题，接入传送带加工流程。
- 修复大猫猫及其 Boss 使用新鲜动画猫咪材质时的眼睛显示问题，适配眼睛纹理位置。大猫猫仍保留自己的模型与动作，并非套用新鲜动画的完整 CEM 动画。

## 性能与更新说明

- 减少高频词条等级查询时的临时 Stream 对象创建，保持原有查询结果。
- 错开多只钓鱼猫的周期工作检查，减少同一游戏刻内集中扫描。此项为局部优化，不代表已定位或解决所有服务器卡顿。
- 用户反馈日志中的猫实体同步字段类型冲突按要求暂不处理，本版不包含该问题的修复。
- 本版未接入机械猫高达原型；保留现有物品 ID、存档数据及饰品、词条脚本 API 兼容入口。
- 客户端和服务端请使用对应加载器的同版本 JAR，更新前建议备份存档及图片库。

详细使用说明见 [猫画编辑桌使用说明](cat-painting.md)，此前正式更新见 [2.3.2 更新日志](changelog-2.3.2.md)。
