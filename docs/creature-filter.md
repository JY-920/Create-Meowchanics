# 生物过滤器与自动激光标记器

适用版本：Forge 1.20.1、NeoForge 1.21.1；物品 ID：`laowu:creature_filter`。

## 使用

1. 主手持过滤器，右键打开机械动力风格的配置界面。
2. 勾选被动、中立、敌对类别；左侧目录支持名称或 ID 搜索。
3. 选择白名单或黑名单。点击左侧添加种类，点击右侧移除；两栏可分别滚动。也可输入完整生物 ID。
4. 右键自动激光标记器背后的方框安装。空手右键同一位置取出；拿另一个过滤器可以替换。

类别和名单必须同时满足。空白名单不匹配任何生物；空黑名单允许勾选类别中的全部种类。默认过滤器开启全部类别、使用空黑名单。每份名单最多保存 64 个 ID。

未装过滤器时保留原有敌对目标识别。安装后机器在 24 格内选择符合条件、视线无遮挡的最近生物，并指挥 5 格内坐垫上的机械猫；猫咪仍遵守原有玩家、主人和友方宠物保护规则。筛选不会绕过这层保护。

## 分类和存储

- 分类按物种固定，不随当前仇恨或队伍变化：优先原版 NeutralMob 与部分原版中立种类，其次 Enemy/MONSTER，其余生物为被动。
- 玩家、掉落物、弹射物不属于可选生物目标。蜘蛛按原版敌对类型识别。
- 格式正确但当前未加载的模组生物 ID 会保留，重新安装对应模组后无需重填。
- 配置自动保存到过滤器物品。机器存档保留过滤器；拆除机器会返还过滤器。
- 六向安装后，过滤槽及显示图标跟随机器一起旋转。
