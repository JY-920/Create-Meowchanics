# 生物过滤器与转信器操作

过滤器上排是规则搜索／切换，右侧依次为编辑属性、添加规则、删除规则。下排可按名字或 ID 搜索目标；滚轮选定或回车确认后直接应用，不需要再绑定一次。

目标可选全部生物、全部和平生物、全部中立生物、全部敌对生物，或某一种具体生物。分类沿用现有按种类判断的逻辑，不因一只中立生物暂时发怒而变更分类。

点上排的属性按钮后，下排改为属性、比较符和数值。右侧两个加号添加正向／反向属性。底部三个名单按钮分别表示当前规则属性满足任意、全部、均不满足；规则之间为“或”，同一生物不会重复计数。没有属性条件的规则直接匹配所选目标。

例如：规则一选择全部敌对生物，再加生命值小于 5；规则二选择猫，再加已驯服。满足任一规则即通过。旧版过滤器及其保留的旧规则分支继续按原本的含义运行。

转信器只保留一个输出模式选择框：

- 阈值：数量达到上限切换，降至下限复位，中间保持原状态。
- 计量：数量从下限到上限时，信号线性从 0 到 15（向下取整）；信号反转后为 15 减去原信号。

悬浮两侧火把可看对应端点的输出条件。手持生物过滤器对准方块顶部中央槽位右击装入，空手右击该槽位取出；蹲下右击仍用于固定／取消检测范围显示。
