# 生物过滤器与生物转信器：分组规则试用版

## 过滤器配置

属性条件放在生物过滤器里，转信器只负责范围、数量和红石输出。自动激光标记器也会使用同一套过滤规则。

- 每个分组选择一种生物（或所有生物），再添加属性条件；支持名称或 ID 搜索。
- 第一版支持成年/幼年、已驯服/未驯服、当前生命值和生命百分比。
- 每一只生物独立套用条件，不需要给每只实体单独配置。组内选择“任一 / 全部 / 均不满足”；不同组之间是“或”。同一只生物满足多个组时仍只统计一次。
- 例如：第一组选择猫，条件为已驯服且生命百分比低于 50%；第二组选择牛，条件为成年。机器统计满足任意一组的生物。
- 不支持某项属性的生物不因反选而通过。例如，不能驯服的牛不属于“未驯服宠物”。
- 最多 8 个组、总计 64 个条件。旧过滤器继续保留原来的判断方式；添加分组时，保留的旧规则作为可见的“或”分支，也可明确移除。

## 转信器红石输出

使用机械动力原生界面与控件。旧存档默认保持阈值模式。

| 模式 | 行为 |
| --- | --- |
| 阈值 | 数量达到上限时输出 15，降到下限时输出 0，中间区间维持之前状态，避免反复闪断。 |
| 计量 | 下限对应 0，上限对应 15，中间按比例向下取整，范围外限制为 0 或 15。 |
| 反转 | 输出 `15 − 未反转信号`，对上述两种模式均有效。 |

计量例子：下限 0、上限 15 时，每多一只生物加一级；上限 150 时，每十只加一级。四面的红色指示区域随实际信号显示亮度。

## 范围与过滤器操作

- 空手蹲下右击转信器：持续显示球形统计范围。再次操作、经过 3 分钟、方块被破坏或离开世界后关闭。
- 打开配置页时仍有临时范围预览；主动开启的范围不会因为关闭界面而消失。
- 正常右击安装手持生物过滤器；从配置页的过滤器图标取回已安装的过滤器。
- 统计半径沿用 1–16 格，实体位置必须在球内；不统计玩家，墙壁不阻断统计。
