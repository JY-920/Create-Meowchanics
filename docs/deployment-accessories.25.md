# 职业反馈修复 / accessories.25

公开版本仍为 2.1.4，内部版本为 2.1.4-dev.accessories.25。

## 本次改动

- 默认套装说明首先显示职业类型；Ctrl 战斗详情补上“攻击伤害”标题。
- 飞行员说明不再包含旧背包迁移文字，飞行员/潜水员说明移除属性 100 封顶相关措辞。仅改文字，旧背包取回兼容、速度/耐力成长机制不变。
- 治疗、音乐的临时表现状态按世界、UUID 和真实实体实例隔离；防止同一运行时实体 ID 的客户端、服务端或预览对象相互影响。客户端使用服务端已同步的施法状态播放动作。
- 医疗和音乐范围圈独立于模型轮廓网格收集；音乐补上紫色范围圈。使用一次相机变换，恢复投影、模型视图与着色器颜色，按距离提高边缘可见度。原有绿框、十字和紫框、攻速图标保留。
- 特工三种近战动作顺序轮换，每个至少 12 tick，不会被高攻速重复重启动作；不增加伤害次数。高智力且有队友、被锁定时，即便第一次随机寻路失败或自己没有攻击目标，也能使用烟雾。保留智力 60、12 格队友范围和 10 秒烟雾冷却。
- 潜水喷水略抬高，并增加原收集网的花状水粒子；复用已有粒子类型及网络编解码，没有新增 Mixin。
- 蟑螂新增展翅跳扑，起跳约 3 秒冷却；跳扑与普通攻击共用属性攻击冷却，一次跳扑最多一次成功命中。不改群体属性加成或耕地工作能力。
