# 特工猫烟雾取消智力门槛

内部构建：`2.2.0-dev.agentsmoke.1`，基于 `2.2.0-dev.chunkload.1`。

- 烟雾隐蔽/掩护撤退不再要求智力至少 60，智力为 0 也可正常使用。
- 保留被敌人锁定、12 格内有友方猫和 10 秒烟雾冷却等条件；独自作战仍不会烟雾撤退。
- 隐蔽持续时间仍为 50 tick，治疗烟雾饰品效果不变。
- 绕后门槛仍为智力 60；智力影响暴击倍率、坐垫警戒范围的机制不变。
- 双端中英文默认战斗说明和 Ctrl 详情同步区分绕后与烟雾条件。

Forge / NeoForge 真实游戏 KubeJS 回归各 81 项通过（原 ProtoChunk 专项为显式开关项，本轮未开启）。强化的烟雾用例检查智力 0/59/60/100、无队友/无仇恨的限制、冷却到期边界；并验证零智力猫通过正式 AI 实际投弹、解除仇恨，隐蔽到期后能够重新锁定且冷却内不重复投弹。

双端正常 build、公开 API v3 快照、发布隔离、每端 23,252 项饰品检查、27 组源码/资源检查及运行包资源校验通过。与 chunkload.1 的 JAR 逐条目比较，仅 CatAgentCombatGoal.class、两种语言描述及版本元数据改变；暮色死锁修复所在 CommonEvents.class 完全不变，测试不混入运行包。
