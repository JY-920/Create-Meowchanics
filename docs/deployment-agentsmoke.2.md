# 特工烟雾不再计入辅助队友

内部构建：`2.2.0-dev.agentsmoke.2`，基于 `agentsmoke.1`。

- 在原有队友筛选中增加职业类型判断，排除 SUPPORT。目前包括医疗、音乐和物流猫；不硬编码职业名单。
- 只有辅助队友在附近时，不满足烟雾隐蔽/撤退的触发条件。辅助队友与非辅助队友共存时，后者仍可使条件成立。
- 原有非辅助猫（包括无职业猫）的判定不变；仍需友方、已驯服、存活、非自身、距离不超过 12 格。仅更改触发条件，不改变已经生效的烟雾。
- 保留烟雾不受智力限制、被敌人锁定、10 秒冷却等规则；不修改治疗烟雾、辅助职业的治疗/增幅效果或其他智力机制。
- 双端中文、英文默认说明及 Ctrl 详情已同步写明非辅助队友条件。
