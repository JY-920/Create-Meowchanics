# 搜索与新鲜动画兼容修复：2.3.0-dev.compat.1

2026-10-13 22:55:50 已备份并部署 Forge 1.20.1 / NeoForge 1.21.1 两个本地开发实例。公开版本仍为 2.3.0；本轮没有提交、推送或覆盖公开发布包。部署路径、旧包备份、SHA-256 和单一启用版本检查见 [部署记录](deployment-search-fresh-compat.1.json)。

## 修复内容

- 搜索故障来自旧创造栏 Mixin 对滚动字段的依赖，不是物品重复注册。改为可选 JECharacters 查询出口兼容，保留不同 NBT／组件的合法变体、原结果顺序、外部物品和非物品查询结果；不修改搜索模组 JAR 或配置。
- 普通猫通过标准 CAT 模型层使用资源包的模型及动画系统，不再只取贴图而丢掉独立眼睛网格。
- 混合花色合成保留资源模型额外使用的贴图区域，从当前 cat.jem 读取已识别眼睛部件的 UV，按左右眼材质分别合成；保留资源包动画。
- 哈气、猫饼、博古架、套装和特殊外观需要本模组几何／骨骼时使用自身姿态及相匹配的原版 UV 贴图；普通状态恢复资源包模型。圆头、街舞和琵琶只在实际专用表现生效时接管，走路等非演出状态不因持有词条而永久丢失资源动画。
- 缓存随资源重载释放；无资源模型时保持原有模型，不增加 EMF／ETF 强依赖。

## 实际验证

资源组合：Fresh Animations 1.10.4、EMF 3.3.11、ETF 7.2.5。Forge 使用正式 SRG 运行环境和当前成品 JAR，NeoForge 使用真实隔离客户端；测试世界为既有隔离世界副本，未打开玩家存档。

- 正常 build 双端通过：冻结饰品 API v3、词条 API v1、动画资源检查、发布隔离以及各 23274 项饰品检查。
- 搜索回归双端各 14 项通过。Forge 正式客户端分别验证 Create／JECharacters 安装与未安装；独立测试 AT 将创造栏滚动字段改为 public，目标类正常加载。安装时真实 FakeArray 的物品、合法变体及泛型调用检查通过。
- 渲染先复现旧实现没有 EMF 模型根、原版专用姿态眼睛像素丢失，以及混合花色额外眼睛区域透明；修复后双端真实客户端通过眼睛部件、随时间变化的动画、左右眼不同材质、持有街舞词条时走路、哈气、猫饼、套装、驯服项圈、恢复普通模型，以及 vanilla → Fresh 资源重载检查。Forge 另外验证 Create 安装／未安装两种组合。
- 项圈回归双端各 3844 项通过；原配置、词条、指令飞行、剪毛、过滤、职业和激光轮盘回归通过。
- 成品 Mixin 包／导航字节码回归 400 项通过，旧 CatCreativeSearchMixin.class 不在 JAR 中；测试插件只按配置的 IMixinConfigPlugin 契约放行，普通运行类型仍不能混进保留包。
- 主审实际打开截图核对普通眼睛、混合左右眼和本模组专用姿态；独立代码审查的两个重要问题已修复。

## 范围与保留事项

未取得报错者的完整整合包，本次模拟并验证的是崩溃堆栈中的字段可见性冲突，不宣称测试了对方所有模组。资源包验证针对上述版本；其他任意 CEM 层级、未来 EMF 内部实现、Boss 自身模型不在本次资源动画兼容承诺内。博古架路径做了源代码检查，没有本轮单独的架上视觉录像。

审查保留的轻微项：演出接管使用当前步行速度，原版模型使用插值速度；恰好跨过 0.08 阈值时可能有一帧判定差异，不涉及眼睛丢失或启动崩溃，本轮不扩大修改。

实施裁定：沿用已存在 develop 工作树并保留所有未提交预览文件；Forge 渲染测试使用正式 SRG 客户端而不改第三方 EMF 的注入；不替换玩家资源包或安装新的强前置。若未来其他资源包改变模型协议，需要另行适配和实测。
