## 实现边界

- 同名饰品、同一种机制不叠加；护胸与不倒翁由饰品槽规则和数据解析共同强制互斥。
- 冷却保存到猫的 NBT，换下、重戴及正常保存读取均不会重置冷却；移除饰品清除其临时护盾或攻速增益。
- 连击层数为瞬时战斗状态；追加攻击和反伤不产生额外连击或暴击加速触发。
- 护盾独立于原版吸收值，不覆盖其他模组的吸收效果。先经过正常护甲与吸收，再处理猫咪护盾/伤害上限；追加攻击也不能绕过防御饰品。
- Forge 的 LivingDamageEvent 早于实际扣血，NeoForge Pre 还早于吸收处理。两端分别适配，只在实际扣血后触发命中机制；新增的实体伤害 Mixin 仅在 RETURN 观察结果，不重定向伤害方法，也不涉及界面渲染。
- 区分伤害取消、九条命保命、普通命中和击杀；为嵌套脚本/辅助伤害保留外层结算上下文，避免丢失外层冷却或错误叠层。
- 暖绒围巾在治疗事件统一增幅一次。医疗猫/治疗烟雾仍先按最强来源合并，不叠加治疗速度。
- 收纳布袋只读货物栏样品，饰品槽不充当样品。仍检查拾取权限、延迟、墙体、堆叠规则与剩余容量；兼容磁铁及狩猎词条掉落物收集，不限制玩家手动放物和工作产出。
- 条件战斗力与猫薄荷增益沿用服务器到客户端的饰品状态同步。协议更新为 Forge 33 / NeoForge 26。
