# 巨猫体型、待命与动作调整

## 玩家行为

- 生命属性 100 对应此前的巨猫尺寸；长宽高倍率为 `sqrt(max(1, 生命属性) / 100)`。25 是一半，400 是两倍，10000 是十倍。不新增体型上限；0/负值按 1 保留非零实体。
- 使用生命属性而非当前血量，因此受伤不缩小。基础遗传属性仍遵守既有 0..100 上限；加上职业、词条与脚本/饰品加成后，体型专用计算不采用战斗属性的 999 截断。原有战斗计算与 API 保持不变。
- 模型、阴影、猫碰撞箱、骑乘碰撞箱和座位随尺寸变化。玩家本身体型不缩放。极大实体仍受已加载区块、世界边界和实际空间限制，不绕过它们强行骑乘。
- 主人空手蹲下右键切换趴下待命／起身；复用原版猫的待命存档和同步状态。空手普通右键仍骑乘，Shift 仍下车。
- 2026-10-01 调整为侧躺：身体滚转到一侧，前腿向侧前方伸展，后腿放松弯曲并错开；躺下与起身可中途平滑反向。动画根据模型实际顶点修正接地高度；起身过渡期间同样锁定身体朝向。

## 画面修正

- 行走朝向优先跟随实际位移，身体转向使用最短角度平滑；头部独立、小幅看向目标。减少跟随玩家时来回扭头。
- 奔跑根节点最大上下位移降为 0.18 模型像素，身体俯仰最大 1°。Q 弹主要放在身体及腿部局部压缩和伸展；物理座位不跟随动画抖动。
- 修正第二段尾巴的父子层级和连接点，并保持原纹理、UV 和立方体尺寸。仅更改导出工程，用户原始归档不改写。
