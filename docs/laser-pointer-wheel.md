# 激光笔轮盘、猫咪血条与战斗模式

Forge 1.20.1 / NeoForge 1.21.1 使用同一套规则。普通右键仍是移动/攻击指令，无额外挥手动作；蹲下右键改为打开轮盘，不再直接切换归属预览。

## 操作

- 轮盘三个区域：猫咪血条、团队显示、战斗模式。左键点击区域或按 1 / 2 / 3 切换，可连续配置多个项目。
- 点击中心、右键或按 Esc 关闭。世界不暂停，不打开背包；拿开激光笔或玩家死亡时关闭轮盘。
- 按住打开轮盘的右键不会连续开关。使用实体、空气、方块时走同一个入口，主手、副手均可。
- 首次打开或提交战斗模式时显示「同步中…」，服务器回执后显示实际档位；显示开关不需要等待服务器。

## 两个显示开关

默认关闭，保存到客户端 config/laowu-client.toml：

- cat_health_bars：仅为 48 格内存活且对玩家可见的已驯服宠物猫显示实时生命百分比和血条，不显示野生猫，不限制猫主人必须是自己。原版同步生命值/最大生命值，客户端平滑跟随猫咪位置，不发送逐帧数据包。不把猫咪六维生命属性误作生物当前生命值。
- cat_team_preview：64 格内宠物猫显示原有团队色轮廓及主人头像。不高亮主人，不修改服务器的发光标记或原版队伍。
- 两项互相独立，只影响本人；F1 隐藏界面时不显示。换世界仍使用本机显示偏好。
- 血条位于头像下方，使用用户提供的原始 64×64 血条.png；不修改源图。动态清除示例文字，再从图中截取百分号与 0–9 字形。保留四边黑框，当前值/上限变化实时更新，显示范围 0–100%。存活的极低血量至少显示 1% 和一个进度像素。
- 100% 使用第一条 64×12 边框；00%～99% 使用第二条 60×12 边框，个位数补零，长度变化时仍以猫咪为中心。
- 血条填充色按实际生命比例连续插值：满血浅绿（#A8E6B0）、半血浅黄（#F2DEA0）、濒死浅红（#F2A6A6），中间平滑过渡而非分档跳色。只为填充区设置顶点色，原始图集、边框、背景与数字不变；补偿图集浅色像素的原色，避免染色后偏暗。
- 本功能显示世界中的猫咪生物，不为背包猫饼新增血条，也不替换已有属性面板。

## 战斗模式

每个玩家在每个世界独立保存，默认「仅指示或保护」，不按单根激光笔储存。

1. 仅指示或保护：不进行新增的主动敌对索敌。保留激光指令、反击、跟随主人攻击以及原有智力相关的友方保护。
2. 主动攻击敌对：在以上基础上，自动选择附近可见的敌对生物。索敌距离不超过 16 格，并受实际视野属性限制；每只猫约一秒扫描一次，错峰执行。未被激怒的中立型生物不主动攻击。

共同边界：

- 仅控制设置者自己的宠物猫，未驯服猫不受影响。
- 物流猫仍只提供支援；坐下、坐垫工作、猫饼姿态、正在被查看或没有 AI 的猫不主动作战。
- 普通猫使用原版近战伤害/间隔，职业猫沿用各自职业攻击方式、套装配置、智力机制，不改变伤害公式。
- 玩家已下达的移动/攻击指令优先；仍受原有 96 格战斗距离规则约束。
- 团队友伤规则不变。不同项圈颜色的宠物视为中立，不因开启主动攻击就自动混战。
- 关闭主动攻击后会停止该功能取得的主动目标；若该目标已成为反击、保护或明确指令的对象，不错误中断防卫。
- 当前按「控制普通索敌，保留词条特殊行为」实现，史迪奇、手贱、食子等词条自身行为不被移除。

## 持久化与权限

服务器主世界 data/laowu_cat_combat.dat 保存玩家 UUID 对应的战斗档位，换维度、退出重进、死亡重生、替换激光笔都不会清空。未记录玩家默认为防御；只保存开启主动攻击的 UUID。设置读取当前猫主人，不把偏好写进猫咪遗传数据或随猫饼继承。

服务器只接受持有激光笔且存活的发送者的 -1（查询）/0（防御）/1（主动）请求；数据包不接受客户端指定其他玩家或猫咪 UUID。普通玩家可调整自己的猫，不需要管理员权限。显示选项从不决定服务器战斗逻辑。

## 验证

- 双端构建。
- tests/run-global-world-config.ps1 新增轮盘回归：真实 NBT 保存/重载、玩家和世界隔离、无效数据容错、逐像素绘制/点击一致性、百分比及边界、图集字形、四边黑框、三色端点及连续性、非填充区域不染色。
- tests/laser-wheel-wiring.mjs：双端接入、控制权、坐下/职业/团队/视野/扫描频率守卫、无逐帧网络包、翻译及共享类一致性。
- 回归产出 tests/build/laser-wheel 下的离线几何与血条像素预览。预览复用生产几何/血条绘制计划，不代表实际 Minecraft 字体、光影和世界战斗实测。
- 游戏验收：主副手对空气/方块/猫咪打开，切换两个独立显示，半血/满血；主动搜索僵尸但不打中立宠物；切回防御停止主动追敌，同时保留反击/激光指令；坐垫及物流猫维持工作；多人、重生、换维度后偏好正确。
