# 猫加工机器操作调整 — 2026-09-26

本次在 2.2.1 上调整现有四项交互，不改配方、公开 API、物品 ID、玩家配置或世界。

## 使用方式

- 猫搅拌器通入动力后，搅拌桨按 Create 原版待机转速旋转；没配方时保持收起，只有加工时伸出，断开动力后停止旋转。
- 猫冲压机、猫搅拌器默认自带一对相反方向的传动轴接口，不再通过扳手开关。旧存档的 shaft_open 属性保留读取兼容，但不再关闭接口。
- 接口保留原贴图及外框，内部开口面内凹 1 个模型像素（1/16 方块），用静态模型补齐四个内壁，避免传动杆与平面重叠。
- 扳手右键绕所点击面的轴顺时针旋转 90°，同步旋转工作端与传动轴方向，采用 Create 的旋转及动力网络更新机制。潜行扳手仍为快速拆除。
- 手持上述机器，潜行右键猫置物台／工作盆的实际工作面，可以直接放到沿该面两格处，中间留一格。六向和原版直立 Create 盆／台均适用。普通点击、其他面点击维持普通放置。
- 快捷放置不覆盖已有方块，间隔被挡、超出建筑高度/世界边界或没有操作权限时失败，不消耗物品。普通放置仍只禁止紧邻盆／台工作面的那一格。
- 放好不代表能加工：搅拌器依旧只配工作盆；冲压机配工作盆或置物台。加工仍需要同向、间隔空置，并满足原版配方、转速与热量条件。
