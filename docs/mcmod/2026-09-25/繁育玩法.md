# 猫咪繁育教程

<!-- 下文至“编辑核对记录”前可用作公开教程。按 Forge 1.20.1、模组 2.2.1 当前源码核对。 -->

## 第一次使用繁育箱

繁育箱用两只成年猫饼和专用繁育猫粮生产小猫饼。父母不会被消耗，每次完成繁育只消耗一份猫粮。繁育箱不需要接入旋转动力。

准备两只成年猫饼，手持猫饼右键繁育箱，依次放入父亲栏和母亲栏；再手持繁育猫粮右键放入猫粮栏。两只猫都能参与繁育、猫粮足够且子代栏为空时，繁育会自动开始。带有“只贴不生”词条的猫不能作为父母。

空手右键可以打开状态界面。这个界面用于查看父母、属性、词条、进度和突变率，不能像箱子界面一样拖动物品。默认显示当前属性，按住 Shift 查看属性上限；悬停数字、词条和说明图标可查看详情。

完成后，蹲下右键取出小猫饼。连续蹲下右键的取出顺序是：小猫饼、全部猫粮、母亲、父亲。要连续生产，应及时取走小猫饼；子代栏被占用时不会开始下一轮。改变父母栏或猫粮栏的内容会使进度清零，包括中途补充猫粮，建议提前备好一批猫粮。

普通“猫粮”不是繁育箱耗材，不能放进猫粮栏。它用于使幼猫长大；繁育箱使用的是“繁育猫粮”“突变猫粮”及六种属性繁育猫粮。

## 三种繁育箱

| 繁育箱 | 标准耗时 | 基础突变率 | 自动化 |
| --- | --- | --- | --- |
| 初级繁育箱 | 2 分钟 | 10% | 仅手动操作 |
| 中级繁育箱 | 1 分 30 秒 | 15% | 支持分面输入、输出 |
| 高级繁育箱 | 1 分钟 | 20% | 支持分面输入、输出和父母更替 |

“猫丁兴旺”可以缩短耗时：每位父母的每级词条减少 5 秒，两位父母的效果相加，最低耗时为 20 秒。表中时间按正常的每秒 20 游戏刻计算。

中级、高级繁育箱的接口以站在正面看向箱子时的方向为准：

| 接口 | 对应内容 |
| --- | --- |
| 正面 | 仅输出小猫饼 |
| 左侧 | 父亲猫饼，可输入、取出 |
| 右侧 | 母亲猫饼，可输入、取出 |
| 背面、顶面、底面 | 繁育猫粮，可输入、取出 |

底部接口不是小猫饼出口。若漏斗放在箱子下方，会取出猫粮，而不是子代。

## 当前属性和属性上限

猫咪有战斗力、生命、速度、耐力、智力、幸运六项属性，每项分别保存当前基础值和属性上限，两者都在 0～100 内。遗传时，这两个数作为一组从同一位父母继承，不会从父亲取当前值、再从母亲取上限。词条、装备等带来的临时有效属性加成不会写入这组遗传数据。

选择亲本时不要只看当前数值。可以在繁育箱界面按住 Shift 查看上限，也可以佩戴工程猫护目镜查看猫饼的属性面板。

## 八种繁育猫粮怎样选择

| 猫粮 | 数值遗传效果 |
| --- | --- |
| 繁育猫粮 | 随机选定五项属性，每项分别随机继承父母之一；剩余一项重新生成 |
| 突变猫粮 | 同样继承五项、重新生成一项；提高突变率，并改变新突变词条的稀有度权重 |
| 战斗力繁育猫粮 | 锁定战斗力，再随机继承另外四项 |
| 生命繁育猫粮 | 锁定生命，再随机继承另外四项 |
| 速度繁育猫粮 | 锁定速度，再随机继承另外四项 |
| 耐力繁育猫粮 | 锁定耐力，再随机继承另外四项 |
| 智力繁育猫粮 | 锁定智力，再随机继承另外四项 |
| 幸运繁育猫粮 | 锁定幸运，再随机继承另外四项 |

六种属性繁育猫粮的“锁定”，是先比较父母对应属性的上限，继承上限较高的一方；上限相同则选择当前基础值较高的一方。如果父母该项上限都达到 90，子代该项上限在较高值的基础上加 1，最高为 100；继承的当前基础值也加 1，但不能超过新的上限。

例如，两位父母的速度上限分别为 96 和 90，使用速度繁育猫粮后，子代速度上限为 97。如果另一位父母只有 89，则继承 96，不会获得这次加 1。两者不需要满足“相差不超过 5”的条件。

每种猫粮都只继承五项，始终留下一项重新生成。即使父母六项上限都是 100，也不代表子代六项上限一定全部为 100。

## 突变影响什么

重新生成的属性会先随机产生一个 0～100 的上限，再在 0～该上限之间生成当前基础值。数值突变成功时，会额外生成一组，保留上限较高的一组；上限相同再比较当前基础值。它不是把已有属性直接加到 90 或 100。

突变率还用于外观和词条：每个外观部位独立判定；词条整体判定一次。未发生外观突变时，各部位分别从父母之一继承，因此后代可能同时具有父母不同部位的材质。

繁育箱的实际突变率计算为：

`（箱子基础突变率＋猫粮加成）×（1＋父母平均幸运÷300）`

这里只有突变猫粮提供加成，为 40 个百分点。参与计算的幸运包含适用的词条修正，双亲平均值限制在 0～100；实际结果可直接查看繁育箱界面。父母平均幸运为 0 时，突变猫粮使三级箱的突变率分别为 50%、55%、60%；平均幸运达到 100 时，约为 66.67%、73.33%、80%。

突变率不是“整只猫品质提高”的概率，也不保证产生指定材质或指定词条。

## 词条怎样遗传

各类繁育猫粮共用以下规则：

- 父母双方都有的可遗传词条优先保留；只有一方拥有的词条，各自进行一次 50% 的遗传判定。
- 遗传及新突变的词条从 I 级开始，不直接继承父母的词条等级。固定等级显示不等于继承了父母的升级进度。
- “面团团”不遗传。服务器禁用的词条也不参与正常遗传、突变。
- 子代最多有四个词条，并遵守词条之间的互斥关系。因此单亲词条通过判定后，仍可能因位置不足或冲突而没有保留下来。
- 词条突变判定成功时，在共有词条未占满四格的前提下，为一个父母都没有的兼容词条预留位置。如果父母共有四个词条，就没有新词条的位置。

普通繁育猫粮和属性繁育猫粮产生新突变词条时，缺陷、普通、优良、卓越的选择权重分别为 30、35、30、5；突变猫粮改为 10、25、45、20。先抽取稀有度，再抽取该稀有度的词条；没有可用词条的稀有度不参与抽取。这些是选择权重，不是每次繁育直接获得某类词条的概率，也不改变亲本词条的遗传判定。

想稳定保留某个可遗传词条，可以先取得两只都带有该词条的亲本。想培养单项上限，则用对应属性猫粮保留高上限，再将另一位亲本的同项上限培育至 90 以上，利用每代加 1 的规则继续提高。

## 高级繁育箱的父母更替

高级繁育箱顶部提供三种模式：

- 锁定：保留当前父母，不主动更替。
- 自动更替：每次成功繁育后，检查两侧相邻容器中的候选猫饼。
- 红石激活：每次红石信号由无变有时检查一次。持续供电不会不断触发更替，也不是用红石控制繁育是否开始。

在箱子左右两侧紧邻放置候选容器，分别用于父亲和母亲。先在繁育箱中放好两位亲本，再把可繁育的成年候选猫饼放入对应容器。更替时，新亲本进入繁育箱，旧亲本放回候选容器；容器必须能够接收换出的猫饼。

两侧的猫咪过滤器可以分别设定目标。不安装或保持默认条件时，箱子按六项属性上限的总和选择更高评分的亲本，不按当前属性判断。设置属性上限范围后，会优先考虑目标范围，并以范围上端作为理想值；例如 50～80 倾向于 80，60～60 倾向于 60。还可以加入词条、成年状态、主人状态、职业和名字等条件。

普通情况下只会换入评分严格更高的候选，评分相同不会更换。当前亲本不符合已设置的身份或生效的筛选条件时，符合条件的候选可能取代它，即使候选的上限总和较低。不要把更替理解为“每一项上限都只能升不能降”。筛选器中的当前属性条件不用于遗传评分。
