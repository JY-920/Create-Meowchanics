# NeoForge 玩家猫咪装备附魔修复

- 1.21.1 的附魔通过 supported_items 与 primary_items 标签限定适用物品。此前玩家猫咪盔甲与工具有钻石级附魔值，但没有加入原版物品类别标签。
- 将猫咪头盔、胸甲、护腿、靴子分别加入 head_armor、chest_armor、leg_armor、foot_armor；剑、镐、斧、锹、锄分别加入 swords、pickaxes、axes、shovels、hoes。
- 九份标签使用 replace: false，只追加猫咪装备，不覆盖原版或其他模组物品。
- 通过原版标签引用链继承保护、效率、锋利、耐久、经验修补等附魔适用规则，附魔台主选物品和铁砧适用物品仍遵循原版各部件限制。例如斧不因此获得剑的全部附魔台选项。
- 不修改装备数值、哈气消耗、染色、现有附魔或物品数据；不涉及猫咪职业套装。Forge 1.20.1 不使用此套 1.21 标签附魔规则，本次不改动。
- 回归检查：将原版所有附魔的 supported_items、primary_items 标签展开，逐项比较九件猫咪装备与对应钻石装备的适用结果。
