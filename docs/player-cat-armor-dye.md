# 玩家猫咪护甲三通道染色

适用：玩家穿戴的猫咪头盔、胸甲、护腿、靴子；不改职业猫套装，不改项圈团队颜色。

## 合成

工作台 3×3：装备必须放正中央，上排从左到右分别放主色、副色、眼睛色染料。眼睛染色仅限头盔，其他三件装备上排右侧必须为空。至少放一种染料，留空的通道保留已有颜色。仅接受原版 16 色 DyeItem，不做颜色叠加/混色；再次放同通道染料为直接覆盖。

已染色装备单独放入任意合成格可清空全部三通道，恢复原始贴图。未染色装备单独放入不产生无意义的重置配方。合成复制原物品全部数据，仅修改染色键和输出数量：耐久、附魔、自定义名字等保持。

NeoForge 1.21 会裁剪 CraftingInput 的空白边框，因此通过 CraftingGridOriginMixin 保存原工作台尺寸和偏移，仅供本配方读取；不修改原版裁剪结果和其他配方判定。

## 贴图与同步

- 三个区域使用原作者调色板映射：橘黄毛色及深色轮廓为主色；白色、奶油色和对应灰色阴影为副色；两档绿色为眼睛色。眼白按 UV 位置排除，含浅灰阴影和纯白高光；粉色鼻子和内耳等细节不染色。眼白四像素坐标：kimi_helmet 的 x=1/8、y=1/2；armor/slim 的 x=11/18、y=11/12；物品图标的 x=5/10、y=5/6。贴图整数倍放大时按标准 UV 同步排除。其他位置的相同浅灰色仍正常参与副色染色。
- 按原像素相对亮度映射染料颜色，高光趋近白色、阴影变暗；透明度原样保留。完全未指定的区域逐像素保持原值。精确恢复默认时直接使用原资源。
- 四种物品图标、标准体型护甲、细手臂胸甲、独立头盔均接入。原 PNG 和模型几何不改；染色物品图标保留原轮廓和像素厚度。
- 每件物品保存整数 LaoWuKimiDyes：三个 5-bit 通道，0=默认，1–16=对应 DyeColor ID+1。Forge 使用物品 NBT，NeoForge 使用 CUSTOM_DATA；沿用原版物品同步，无新增网络协议和客户端类的服务端入口。
- 客户端按实际出现的组合生成纹理，缓存最多 256 个；资源重载释放动态纹理和原图缓存。不会预生成 16³ 组合。资源包若重画了原调色板，需要同步维护 KimiDyePalette 的区域映射。
- JEI 展示 17 个护甲固定示例，已移除非头盔的眼睛染色；不轮播所有组合。实际合成由自定义配方完成。

## 验证

tests/KimiArmorDyeRegression.java 在双端分别测试 4913 种染料/空位组合、保留旧通道、非法位置/多装备/非法染料、2×2 重置、明暗和粉色保护。双端完整构建、资源和部署另行验证。游戏内实际穿戴、护甲架、细手臂、附魔光效、JEI 转移及存档重进仍需客户端实测。
