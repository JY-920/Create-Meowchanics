# 六向猫加工机器 — 使用与验证

版本保持 2.2.1。不提交、推送或修改公开版本号。9 月 25 日初版构建/部署见本文末尾；9 月 26 日放置、交互和图标修正见 `sixway-cat-machines-fixes-2026-09-26.md`，最新机器操作调整见 `machine-controls-2026-09-26.md`。

## 使用方法

- 新增 `laowu:cat_press` 猫冲压机、`laowu:cat_mixer` 猫搅拌器。保留 `laowu:haji_basin` 哈基工作盆和 `laowu:cat_depot` 猫置物台原 ID。
- 盆/台的底面贴着放置面；六个方向都可放。冲压机/搅拌器可独立摆放，仅禁止紧贴盆/台工作面的相邻一格（六向均适用）。加工时机器工作端与盆/台开口相对，中心相距两格，中间空一格；无目标、间隔被挡或方向不符时可以放置，但不加工。放置时优先朝向对齐的盆/台，否则底面贴着点击面。
- 材料右键猫置物台的实际台面进行放入，空手右键取回；横放、倒放与正放遵守同一规则。
- 冲压机可配盆或置物台；搅拌器只配盆。直立可配原版 Create 盆/台。侧放或倒放时，需要同方向猫盆/台。工作空间被堵住或目标无效时停止加工。
- 冲压机、搅拌器自带一对相对轴口，接口面内凹 1 模型像素。扳手右键围绕点击面的轴旋转机器，工作方向和传动轴同步改变；潜行扳手快速拆除。应力负担沿用原版对应机器，盆侧面扳手继续控制局部出料嘴。
- 手持冲压机／搅拌器，潜行右键盆／台的实际工作面，可直接放到两格处并留出一格加工空间；障碍或目标占用时失败，不消耗物品。
- 搅拌桨通电即按原版待机转速旋转，没加工时不会下伸；加工伸缩仍随实际工作进度。
- 需要加热的配方，其热源放在盆的底面一侧。横放与倒放的库存/流体不会因视觉重力洒落；真实掉落物仍遵守 Minecraft 重力。
- 沿用 Create 原配方、容量、过滤、序列组装进度和输出队列。JEI 使用现有分类，没有克隆配方页。本次未新增机器合成配方。

## 实现边界

共享 bottom 坐标系控制目标查询、热源、盆口、侧向能力、物品/流体和动画。旧状态默认 bottom=down，保留原物品/流体 NBT。Mixin 限定猫类型，原版机器不整体替换。原版操作器只在对齐时与猫盆交互。

静态外壳及内凹轴口与动态压头/杆/套筒/桨分开导出；原 PNG 字节不变。伸缩进度取 Create 实际加工状态；搅拌桨同时保留原版通电空转。没有独立 Flywheel visual，因此 BER 明确渲染轴与动态部件，避免全局 Flywheel 开启后遗漏。

## 未夸大的范围

测试使用精确项目依赖 Create 6.0.8-291 / 6.0.10-281。未承诺任意其他 Create 版本或第三方机器组合都兼容；未专门验证装入运动结构后的六向运行。只修改测试副本，未读取或改写玩家世界。早期 Forge 出料曾出现一次 EAST count=0，后续多轮未重现，保留 NBT 诊断并继续全方向回归，不将原因武断归于生产代码或测试环境。
