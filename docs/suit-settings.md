# 套装配置（双端）

Forge 1.20.1 / NeoForge 1.21.1 共用参数、默认值、公式和权限语义。

## 界面

V → 世界设置 → 套装配置。左右按钮切换七种职业，分组按钮在「战斗与防护」和「属性加成」间切换：

- 战斗与防护：伤害系数 K、基础攻击间隔、速度缩短系数、最短攻击间隔、直接生命值／护甲值／韧性加成。
- 属性加成：战斗力、生命、速度、耐力、智力、幸运属性的临时加成。

切换职业和分组会保留草稿，包括暂时无效的输入；任何职业存在无效输入都不能保存。整数项目拒绝小数，所有项目拒绝 NaN、无穷大及越界值。

「恢复默认」重置当前套装两组内的可编辑项目，不影响其他套装；全局锁定项保持原值。点击保存才提交，服务器重新检查权限、数值、全局锁和版本。非管理员只能查看。物流猫保持辅助职业，四个攻击参数灰显，不控制物流支援频率。

下方保留 0 / 50 / 100 / 150 基础属性示例；查看不同输入框时显示对应攻击伤害、攻击间隔、生命值、护甲／韧性、移动倍率、暴击伤害倍率或暴击率。预览采用当前套装全部草稿和已经生效的世界属性倍率，不重复叠加套装属性。

## 攻击速度

`间隔tick = max(最短间隔, round(基础间隔 − 速度缩短系数 × 当前速度属性 × 世界速度倍率))`

20 tick = 1 秒，理论每秒攻击次数 = 20 ÷ 间隔。当前速度属性已计入套装和词条。

- 基础间隔、最短间隔：整数 1～999999，越小越快。最短间隔优先，即使大于基础间隔也有效。
- 速度缩短系数：0～999999，可用小数；设为 0 可关闭速度属性缩短间隔。
- 原先隐藏的 60 tick 上限移除；默认参数未改，默认攻速与旧版本一致。
- 不突破一 tick 一次攻击、目标原版受伤无敌帧、飞行员俯冲/移动耗时；预览并非保证实际命中频率或最终 DPS。
- 不改变职业移动 AI、射程、攻击方式、弹幕击退规则、物流支援频率或工作效率公式。

## 加成与生效时间

直接生命值／护甲／韧性加成允许 0～999999（可用小数），直接加在生物属性上，不乘六维属性倍率。六维属性加成为整数 0～999999，进入当前有效属性后再参与对应属性倍率和能力公式，不修改基础属性、培养上限或遗传数据。有效属性仍截到 0～999，原版生命／护甲／韧性／攻击属性上限仍有效。

已穿戴猫咪不需要重新穿戴：伤害系数在后续 tick 使用，直接防护及六维属性加成约一秒内刷新，不重装套装、不清除目标。降低最大生命值会限制当前生命值，生命属性转换沿用原有血量比例处理，不额外执行满血治疗。

攻击间隔在下一次攻击冷却计算时使用新值；当前已计时的冷却不强行清零。已射出的弹幕仍保留发射时伤害。客户端收到服务器同步后，套装 Ctrl 说明、Shift 50/100 示例和猫咪属性面板使用新配置。

## 存档与全局文件

旧的 `[career_damage_coefficients]` 路径和数值完全保留。新增参数放在 `[career_settings.<职业ID>]`，不把旧 K 迁移到新位置，也不重置原有系数。加载更新包后自动补齐缺失配置与中文默认值注释。

- 存档：`saves/<世界>/serverconfig/laowu-server.toml`，每个世界独立。
- 全局：`config/laowu-global.toml`，新项目默认 `-1` 使用存档；其他有效值强制覆盖并锁定。改回 `-1` 恢复存档原值。
- 联机只认服务器/房主的全局文件，客户端本地全局文件无权改服务器规则。

示例：全局强制机械套装生命值加成 40、基础攻击间隔 30，其余跟随世界：

```toml
[career_settings.terminator]
health_bonus = 40
attack_interval_base = 30
attack_interval_per_speed = -1
minimum_attack_interval = -1
armor_bonus = -1
toughness_bonus = -1
attack_stat_bonus = -1
health_stat_bonus = -1
speed_stat_bonus = -1
stamina_stat_bonus = -1
intelligence_stat_bonus = -1
luck_stat_bonus = -1
```

完整注释示例见 [laowu-global.toml](config/laowu-global.toml)。文件热重载仍依赖加载器；不确定是否重载时，退出世界后编辑，重新进入世界最稳妥。安装新 JAR 本身需要重启游戏。

## 兼容和检查

保留所有职业 ID、原始默认值、伤害系数 TOML 路径、属性修饰符 ID 和猫咪 NBT。NeoForge 属性计算层构造相同资源 ID 时不再触发整个模组注册类初始化，ID 内容不变。

配置同步协议升级：Forge 19 / NeoForge 12；客户端与服务器应同时更新，旧的不完整配置包被拒绝，不能将缺失参数写成 0。

`tests/run-global-world-config.ps1` 包含真实配置规格、8192 种重置锁组合、远程隔离、伪造锁写入防护、参数校验、默认攻速等价、真实六维有效属性转换和旧文件值保留；`tests/career-damage-wiring.mjs` 检查双端接入、草稿与保存、动态说明、翻译和既有无击退逻辑。

离线检查不能替代实机界面及多人战斗验证。
