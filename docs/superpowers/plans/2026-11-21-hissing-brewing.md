# 哈气药水酿造

Forge 1.20.1 和 NeoForge 1.21.1 都使用原版酿造台、燃料槽和三瓶批量处理。

1. 在两端的服务器 GameTest 中使用真正的酿造台。检查猫粉、烈焰粉、荧石粉依次酿出 I、II、III，火药与龙息改变瓶型，红石把同级药水从三分钟延长至八分钟。先验证当前版本缺少配方。
2. 注册三个长效药水，保留现有药水 ID、效果等级和一次近战消耗的行为。无机械动力时注册基础与升级配方，包括长效 I、II 的升级。两种环境都支持红石延时。
3. 在有、无机械动力的两个版本中验证瓶型、延时、升级、原版药水以及现有工业配方，构建双端运行包，并核对部署与远端提交。
