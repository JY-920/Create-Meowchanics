# 自动激光标记器与激光猫工作模式设计

日期：2026-10-03。适用 Forge 1.20.1 / NeoForge 1.21.1。

状态：用户已确认聊天方案；本文待用户审阅。尚未开始运行代码实现。

## 目标与范围

玩家通过 Create 应力驱动一个六向安装的自动激光标记器，指挥附近坐垫上的激光猫原地攻击敌对生物。机器索敌范围与工作猫参与范围固定，不受猫咪属性影响，攻击伤害、攻速及饰品效果仍来自现有猫咪系统。

同批将猫机壳的底材由去皮原木／木头改成 Create 纸板块，保留猫锭应用制作方式。双端实现并验证后，按仓库部署约定部署本地实例；不自动推送 Git、修改公开版本号或发布 Modrinth。

## 已确认的玩法

- 猫机壳：`create:cardboard_block` + `laowu:cat_ingot` → `laowu:cat_casing`。支持手持猫锭右键纸板块和动力机械手应用；去皮木不再是有效底材。
- 新机器显示名“自动激光标记器”，追加注册 ID `laowu:cat_auto_laser`；不替换现有方块或物品 ID。
- 机器原模型底面改为应力接口，能朝六个方向安装。仅底面连接传动杆，旋转轴沿底面法线。
- 有正常转速且未超载时展开；停转或超载时撤销标记和工作命令，播放收回过渡。正反转都可工作，无最低转速门槛。
- 以机器方块中心为球心，在三维距离不超过 24 格的已加载实体中标记最近的可见敌对生物。
- 以机器方块中心为球心，三维距离不超过 5 格的 Create 坐垫可作为炮位；驯服、存活、穿着激光套装的猫在实际占据该坐垫时参与。
- 猫保持坐垫上的状态，不解除坐姿、不追击、不传送。猫到被标记目标的发射路径无遮挡时发射现有机械激光弹。
- 工作猫与目标相隔最远约 29 格，不能沿用普通激光猫 16 格攻击半径或激光弹 16.5 格飞行上限。
- 底座姿态、激光笔瞄准方向、激光发射点与客户端红色光束必须一致。六向安装后仍正确瞄准世界坐标目标。

## 实现边界与默认值

以下为书面规格采用的实现默认值，便于审阅：

- 应力消耗系数默认 4 SU，与 Create 动力系统一致随转速计算；不新增玩家必须填写的配置。
- 每 10 tick 刷新附近工作猫和最近目标；无目标时展开待机，不显示打向空处的标记光束。
- 敌对判定包含 `Enemy` 或 `MobCategory.MONSTER`。正在攻击附近工作猫、其主人或友方宠物的中立生物，复用现有 `CatAgentWatch.hostile` 判定。
- 机器无需绑定某个玩家；每只猫独立执行现有队伍、主人、驯服宠物和玩家保护规则，不因机器命令新增 PvP 权限。
- 本轮没有提供新机器配方，因此先注册方块、物品、创造物品栏入口和正常拆除掉落，不擅自设计其生存配方。
- 固定的是索敌／参与范围，属性仍影响现有伤害和攻击间隔；不新增智力门槛。
- 猫自身或目标被检查、进入猫饼／骑乘等不可工作状态时不发射。参与条件按已有猫工作安全规则校验。

## 架构与状态流

### 机器动力与服务器索敌

增加独立的 `CatAutoLaserBlock`、`CatAutoLaserBlockEntity` 和注册入口。复用现有六向姿态辅助类及 Create 的动力、扳手旋转、潜行扳手拆除机制，不改 Create 原生注册。

服务器是索敌、工作命令与攻击的唯一权威来源。客户端只插值展示展开程度、瞄准方向和红色光束，不选择攻击目标、不造成伤害。

状态为“收回 → 展开中 → 工作／无目标待机 → 收回中”。断动力后服务器立即停止新发射，不等待收回动画结束。动力恢复时从当前展开程度继续过渡，不瞬间跳到另一个姿态。

索敌仅查询已加载范围，按机器中心到目标位置的距离选择最近目标；距离相同时用稳定身份排序。目标死亡、移出 24 格、跨维度、卸载或被遮挡后撤销标记并重新选取。每次射击前再次校验范围、存活及遮挡，不能只相信上一次扫描。

### 激光猫独立工作通道

增加独立的 `CatLaserWork`，在现有职业工作 tick 中接入，不使用会解除坐姿的玩家激光笔指令，也不把机器目标写入普通战斗的 `cat.setTarget`。

机器给符合条件的猫更新短期工作上下文：维度、机器位置、目标 UUID、有效期限。工作上下文运行期保存，不写入猫的永久 NBT。射击前确认机器区块已加载、同一方块实体仍在运行、坐垫仍存在且被猫占据。猫离座、换职业、断动力、拆机或卸载后上下文立即失效。

多台机器覆盖同一猫时，只接受距该坐垫最近的有效机器，等距按方块位置稳定排序；每只猫只有一个工作攻击冷却，不能因机器数量增加而叠加射速。

攻击复用机械激光弹、现有职业伤害与 `careerAttackIntervalTicks`，继续调用既有饰品投射物钩子。工作射击不会获得普通战斗的移动、绕行或追击行为，也不改写原玩家激光笔命令。

### 工作激光射程

现有 `MechanicalLaserProjectile.MAX_TRAVEL_DISTANCE = 16.5` 保留为普通战斗默认值。追加每枚投射物的飞行距离／寿命参数，只有机器工作射击使用延长值。

工作弹允许飞行距离至少 32 格，同时不小于实际发射点至目标瞄准点距离加 2 格余量；寿命按实际距离及发射速度 2.4 计算并留出 5 tick 余量。范围资格仍由机器中心 24 格及坐垫中心 5 格决定，不能通过提高猫属性扩大范围。距离与寿命参数必须有限且受服务器构造和读取校验，不接受客户端任意数值。

激光仍受原投射物方块碰撞和友方保护约束，不穿墙、不改为机器直接结算伤害。停止工作不会倒扣已经发射的攻击；已发射投射物正常完成碰撞／寿命清理。

### 客户端模型、动画和光束

输入素材来自 `D:/Project_minecraft/待实现/自动激光/`：`model.bbmodel`、`model.geo.json`、`model.animation.json`、`texture.png` 和 `不亮.png`。只将实际使用资源打进运行包，保留原文件作为美术来源。

沿用现有轻量 Blockbench 渲染路线，不新增 GeckoLib 等必需依赖。原模型为 Bedrock 格式，需要正确转换坐标、组 UUID、零厚度面和负尺寸元素；不得仅改文件扩展名或假设与现有 Java 模型同坐标。

展开参考 `animation.model.new` 的 1.25 秒时序；收回反向采样同一进度。笔架和笔体分别承担本地偏航、俯仰，工作瞄准由实际目标位置驱动，不把演示用整圈旋转直接作为瞄准动作。

底面应力接口复用现有猫机壳轴口贴图，并以内凹面配合传动杆，避免轴和贴面重叠。保留作者外壳与激光笔材质；未运行时采用不亮材质。

客户端由同一套模型／瞄准变换计算笔尖出口，再复用 `CatLaserEffects.solidBeam` 绘制红色、正常深度测试的实心细光束。服务器同步目标 UUID 与实体 ID，客户端核对身份后展示，避免实体 ID 重用。缺失目标、断动力、世界切换或区块卸载后不保留旧光束。

模型与光束的渲染边界需要包含展开部件及最长标记光束，保证摄像机看到光束但底座不在视野时不会错误裁剪。物品栏图标保持收回模型，不溢出格子。

## 现有代码的接入点

双端对应路径分别位于 `forge-1.20.1` 和 `neoforge-1.21.1`：

- `create/CatMachineBlocks.java`：追加方块、物品及方块实体注册。
- `create/CatMachineOrientation.java`：复用六向坐标和姿态，不改现有机器行为。
- `CareerCatBehavior.java`：追加激光猫工作 tick；普通战斗坐姿保护、属性和职业逻辑保留。
- `entity/MechanicalLaserProjectile.java`：追加工作弹飞行参数，保留普通默认值和公开饰品接口。
- `client/CatMachinesClient.java`：追加方块实体渲染注册。
- `client/RuntimeBlockbenchModel.java`、`client/CatLaserEffects.java`：优先复用能力；必要扩展不得改变旧模型或光束默认行为。
- `LaoWuMod.java`、语言文件、模型／方块状态／采集标签／掉落数据：追加创造入口、说明及资源。
- `data/laowu/recipes`（Forge）／`data/laowu/recipe`（NeoForge）：替换猫机壳底材，移除去皮木的制作入口；手动应用和机械手均由真实配方验证。
