# 猫咪部署台

用户明确要求直接执行，不等待二次确认。

两个水平朝向方块：laowu:cat_deployment_platform（猫咪部署台）、laowu:cat_ejecting_deployment_platform（猫咪弹射部署台）。
只接收哈气，4000 mB容量。每次成功还原一只猫消耗250 mB和一个猫饼；不足、阻挡、实体生成失败不消耗。猫饼使用已有完整快照还原，保留主人、成长、背包、饰品、职业、属性和词条。支持手持和自动化放入，顶面掉落物投入；库存只收猫饼。挖掘掉落物保留液体与待部署猫饼，物品存储提示沿用航空箱的格式。支持桶和管道；不接收其他流体。

弹射版使用 Create EntityLauncher 弹道；潜行右键目标块选点，再正常放置。服务器验证维度、同一行/列、非零水平距离，以及 Create 配置最大距离（默认32）。不额外要求旋转动力，目标无效或未加载时保留输入。以原始较新 BBModel 的托盘和杆制作弹射动画。普通版使用作者模型。当前未指定配方，创造栏获取；不擅自设计配方。

不会强制加载世界区块，不修改既有 API 契约。验证双端后按 AGENTS 部署，不提交或公开发布。
