# 猫编辑台首版

用户离开期间直接实施、验证双端并部署，不等待确认。使用提供的猫词条机模型、UI猫大本营图集、词条图标；不改原素材风格。

方块/物品ID laowu:cat_editor，菜单CAT_EDITOR_MENU；词条载体laowu:cat_trait_token。旁边定义为水平相邻四格（坐垫与机器同Y）；只选属于操作者且坐在Create坐垫上的猫。多个按UUID稳定选一个，打开后锁定目标UUID，猫离开坐垫、死亡、距离过远或所有权变化时菜单失效，不能编辑别人的猫。多个玩家/菜单并发在服务器复核。

复用CatGenome/Region的11部位材质系统。外观页显示猫预览、部位选择、一个方块样本槽；应用时服务器验证并消耗一个样本，支持全身或单部位，不改属性/主人/职业。取消关闭归还菜单临时物品。

词条页列出当前词条，拆出整条及其原等级为一个非堆叠token，优先放入输出槽；输出有物品则拒绝。装入消耗一个token，保留完整等级，不加级不覆盖现有同类或互斥条目，遵守4槽限制。支持已有KubeJS自定义词条ID；停用/缺失定义的token保留原数据不可安装，不能清洗其他未知词条。物品描述显示名称、等级、ID和效果（定义存在时）。不用新脚本API或改变冻结契约。

菜单320×240，两个页签，共用3临时槽：方块样本index0(18,123)、词条输入index1(120,123)、词条输出index2(284,123)。玩家背包x80,y158，热栏y216。两页均显示三槽避免隐藏物品迷惑，按钮控制页内操作；关闭时还给玩家，满包掉到玩家旁。持久猫信息由现有同步包更新。完整整数动作经已有CatEditorActionPacket传输，不使用原版byte按钮包。

未指定耗气、应力或配方，不额外添加；创造栏获取首版。正常build、实际server/client测试后部署两开发实例；保留备份，不提交推送。
