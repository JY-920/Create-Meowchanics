# Java 双端博古架与按键

范围：Forge 1.20.1 / NeoForge 1.21.1，兼容有/无 Create；不修改网易工程。

- 保留强化、飞扑、哈气音量按键。显示调节器默认未绑定，不覆盖玩家保存的按键。下降取消注册，直接读取左右 Ctrl，仅游戏窗口激活且无界面时生效。
- 原始 round_bogu_shelf (5).bbmodel 原贴图、UV、旋转不改。底部中间为定位格，九格占位，水平四向；任一格有障碍时整体不放置，破坏任一格清理整体，只掉一件，创造不掉落。阻止活塞推动。
- 右侧大空位支持一只真实猫：空手右键安置附近属于玩家的宠物或野猫（不偷其他玩家的猫），再次右键切换坐姿/展示哈气；蹲下空手右键取下。退出、拆架恢复原坐姿，不复制猫或改变属性。展示缩放适配小空间，巨猫不安置。
- 坐姿和哈气为主动展示，与宠物不自动参与野外哈气规则独立；遵守服务器关闭哈气设置。保存座位和真实乘客，不复制 NBT。
- 暂无陈列物品、GUI、配方；加入猫咪养成创造栏。

验证：原模型导出面积/UV/分块边界；双端真实 GameTest 验证四方向占位、障碍、拆卸掉落、猫状态/所有权/恢复/存储；实际客户端加载模型与按键。双端正常 build 保留全部 API 与发布隔离校验，再安全备份部署。
