# 自动激光光束简化

按确认方案，导出时去掉笔前方两层实体光束，保留原始创作文件、笔身与装饰面；动态光线起点从作者光束末端改为笔口 z=7.9px。仅机器光线使用 alpha=89/255，保留现有透明混合与方块遮挡。旧 solidBeam 调用保持完全不透明，未改变手持激光笔和职业攻击效果。

验证采用先复现后修复：资源检查在旧模型上报告光束突出笔口；NeoForge 旧渲染实际客户端报告光线不透明。修改后资源测试、双端实际客户端六向渲染/72组笔口顶点/光线端点与遮挡/透明度检查均通过，双端 GPU 截图已目视核对。双端正常 build 通过公开 API、23,270 项饰品检查及发布包隔离检查。本次未改变索敌、攻击、KubeJS 事件逻辑，未重跑服务端工作测试。
