# 词条禁用配置（Forge / NeoForge）

## 文件位置与权限

- 单人存档：游戏实例的 `saves/<地图名>/serverconfig/laowu-server.toml`。
- 独立服务器：服务器的 `<level-name>/serverconfig/laowu-server.toml`。
- 全局覆盖：游戏实例或服务器根目录的 `config/laowu-global.toml`。
- 游戏内：按 V → 世界设置 → 词条禁用，搜索名称、固定 ID 或描述，逐项勾选后保存。
- 仅 OP 等级 2 及以上或单人世界创建者可保存。普通玩家只读；全局强制列表下仍可搜索查看，不能修改。

## 填写方法

`disabled_traits` 是 TOML **根级**数组，放在第一个 `[分组]` 之前，不要放进属性倍率或套装系数分组内。两个文件都会自动附上完整的中文词条编号对照（当前 81 个）；固定 ID 不会因列表重排或新增词条而变化。

全局配置的三种写法，三选一：

```toml
# 使用每个地图自己保存的列表（默认）
disabled_traits = [-1]
# 强制允许所有词条新出现，锁定世界内选项
# disabled_traits = []
# 强制禁止夜猫子和上天猫新出现，锁定世界内选项
# disabled_traits = ["laowu:night_owl", "laowu:sky_cat"]
```

世界配置默认 `disabled_traits = []`，可填写同样的 ID 数组，但不接受 `[-1]`。

全局数组完整替换世界数组，不是合并。全局改回 `[-1]` 会恢复原世界列表，不会把原列表覆盖掉。联机时以服务器文件为准，客户端自己的文件不能覆盖服务器。

## 生效范围与旧存档保护

保存 GUI 后立即影响后续的新词条生成；修改 TOML 后由加载器重新载入，在线客户端通常在下一次配置同步（最多约 1 秒）看到变化。若整合包禁用了文件监视，重新进入世界或重启服务器生效。

禁止途径：新猫自然生成、注液猫饼、普通繁殖、繁育箱、繁育棒，以及词条棒新增。禁用词条不参与共有必继承、单亲继承或突变池。父母本身不会被修改。禁用面团团会同时取消注液强制附带该词条。

已有猫咪和猫饼继续保留词条、等级与效果；扫描、收纳/放出、重新读档和升级已有词条不会删掉它。已生成的子代或已完成的猫饼不会被追溯修改。若希望移除旧猫词条，可自行用调整棒明确删除。

不修改词条注册、固定 ID、猫咪 NBT 版本或序列化格式；未知但格式正确的 ID 会保留在配置中并忽略，便于更新兼容。完全禁用所有词条会正常生成无词条猫，不会在空随机池上崩溃。

这是一份“禁止新出现”列表，**不是禁用已有词条效果的开关**。

## 猫咪过滤器

当前属性可配置范围改为 0～300；属性上限页仍为 0～100。猫咪实际数值、遗传上限、倍率上限没有改变。

旧过滤器的数值范围读取时会限制到 0～300，例如 0～999 → 0～300、500～999 → 300～300。保留原来的启用位、全部/任意/反向逻辑、词条、名字、成长、主人和职业条件。不启用的属性条件仍不参与过滤，不会因为猫咪超过 300 而被隐式排除。最早的 0～100 默认范围和旧 0～999 默认范围仍按未启用兼容。

只读解码不会修改原物品 NBT；玩家编辑并保存时才写入新的过滤配置。禁止新出现的词条仍可用于过滤已有猫饼。

## 验证

`tests/run-global-world-config.ps1` 使用双端真实配置规格、词条生成算法和 NBT 读写验证：完整 ID 注释、全局锁定与恢复、服务器权威、旧存档往返、已有词条升级、所有新生成路径排除禁用项、空候选池、恢复词条，以及旧过滤器范围和筛选条件迁移。另运行现有属性倍率/套装系数和过滤器逻辑回归。构建及离线测试不替代实际游戏中的 GUI 视觉检查。
