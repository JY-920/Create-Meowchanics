## 最终结果

- Forge、NeoForge 的真实 KubeJS + 原 36 饰品替换脚本 + 饰品 SDK 示例 + 新词条示例，最新一轮各报告 105/105，通过的 7 个词条场景全部实际执行；两份最终日志的 KubeJS 脚本错误为 0。
- 105 总数包含原有未开启的 ProtoChunk promotion 用例（该用例报告 SKIP 并成功结束）；不声称本轮实际执行了该特殊复现。
- 每端 311 项新增词条数据检查、74 项原死亡属性配置检查、23252 项饰品定义检查；29 组源码检查；284 项物理 JAR / Mixin 检查通过。
- 无 KubeJS 的隔离服务端分别实际执行 1 个核心数据/API/编辑器场景；其余 6 个脚本专用场景跳过，不计为脚本测试通过。
- 正常 build 保留饰品 API v3、词条 API v1、发布隔离验证。Forge 最后一次在线解析遇到 Maven Central DNS 错误，随后使用现有缓存的正常离线 build 成功，没有跳过检查。

## 本轮发现并修正

- 不给没有脚本加成的猫附加空同步字段，保持原存档“不重掷属性/词条”的断言。
- 死亡后的受伤观察回调原本会尝试写入只读状态；现在死猫只接收 death 观察，新增负向断言，并检查最终脚本日志。
- 词条定义重载时更新扫描仪贴图缓存；编辑器按打开时的 ID 列表操作，旧窗口在重载后失效。
- 缺失定义保留存档 ID、等级与状态；格式错误保留上次有效定义；过滤器不会因定义缺失而放宽条件。
