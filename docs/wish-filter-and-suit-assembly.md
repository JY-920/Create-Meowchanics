# 心愿条件过滤与套装组装（accessories.33）

## 猫咪过滤器

手持猫咪过滤器右键心愿领养箱，立即清空旧过滤条件，再复制箱子当前交易的属性范围。不会打开箱子界面，也不会改变锁定状态、奖励或库存。

- NOW：匹配猫咪当前**基础属性**，不计词条、套装等额外加成，与心愿领养的判定一致。过滤器页签显示“基础值”。
- MAX：匹配属性上限。另一页数值限制、词条、幼年/成年、主人、职业、名称和与/或/反选设置全部重置。
- 不要求的属性保持关闭；大于等于、小于等于和区间都按含边界范围导入。
- 复制的是当前交易的快照。箱子刷新后，再次右键即可更新；不会持续自动追踪。
- 手动重置过滤器恢复原来的“当前值”判定（计算词条），原有普通过滤器不改变。
- 由服务端执行，拒绝旁观、超距离、隔墙及同时打开过滤器旧编辑窗口的更新；保留过滤器物品数量和自定义名称。

## 半成品

13 套套装、猫咪构件、猫手雷共 15 个半成品 ID 均保留，换用 Create 原生序列组装物品类型：显示进度条，按原生规则单件堆叠。既有贴图和模型映射不改；猫手雷半成品沿用原来的猫壳贴图，其余使用对应半成品贴图。

所有 31 个机械手步骤都检查实际配方查找、半成品的保存/转移和下一步识别。猫咪构件维持原有 80% 成功率及两个 10% 副产物，没有改变旧平衡。穿戴、脱卸配方及饰品不可合成的规则不变。
