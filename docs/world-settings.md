# 世界级管理员配置（Forge / NeoForge）

## 入口、权限与持久化

进入世界后按 V，选择“世界设置（管理员）”。所有玩家可查看；只有 OP 权限等级至少 2 的管理员，或单人世界主人可以保存。单人世界无需开启作弊。局域网访客不因加入世界而获得权限。

修改是草稿，点击“保存并应用”才提交；返回/ESC 不保存。服务端验证权限、完整字段、有限数值范围和配置版本，拒绝过期编辑，客户端不能用本地配置改变服务器规则。双端网络协议已升级，需要服务器与客户端一起更新。

界面分为“属性与行为”“套装伤害系数”和“词条禁用”三页，共用一份草稿。切换分页不丢失输入；保存同时校验所有页，隐藏页有非法数值时也不能提交。新增词条配置后的网络协议为 Forge 18 / NeoForge 11，旧客户端不能连入新服务端。

标准配置文件：当前存档的 `serverconfig/laowu-server.toml`。

- 单人游戏：实例的 `saves/<世界名>/serverconfig/laowu-server.toml`。
- 专用服务器：`<level-name>/serverconfig/laowu-server.toml`。
- 新世界默认模板可放在 `defaultconfigs/laowu-server.toml`；不会覆盖已有存档。
- 不是 `config/laowu-client.toml`；该文件中的音量、个人附近刷猫偏好仍是独立客户端设置。

## 全局覆盖（2026-09-10）

两个版本都会通过加载器的 COMMON 配置注册，在实例/服务器根目录生成 `config/laowu-global.toml`。它对同一实例/服务器打开的所有新旧存档生效，不是新建世界用的 `defaultconfigs` 模板，也不取代存档原有的 `serverconfig/laowu-server.toml`。

- 六项属性倍率和七项套装伤害系数：全局每项默认 `-1`，沿用各存档设置；设为 `0～999999` 则强制覆盖，支持小数。属性倍率的存档默认值为 `1`，套装系数使用各职业原有数值（见下表）。全局值替代对应存档值，不是再相乘。
- 三个开关 `show_hell_recipes`、`wild_cats_flee`、`cats_hiss`：`-1` 沿用存档；`0` 强制关闭；`1` 强制开启。这里必须写数字，不使用 TOML 的 true/false。
- 每项单独覆盖。GUI 显示最终生效值和 `[全局]` 标记；被覆盖的输入框/按钮不可修改，悬停会说明来源。全部被覆盖时禁用保存按钮。
- 全局强制项即使由 OP 或单人世界主人也不能在游戏里修改。服务端按自己的文件检查锁定状态，不信任客户端发送的锁定标记；保存其他选项不会把全局值写入存档。
- 原存档数值始终保留。例如 A 世界战斗力倍率 1.5，B 世界 4；全局 attack=2 时两者都用 2；改回 -1 后分别恢复 1.5 与 4。
- 联机客户端只使用服务器同步的最终值与锁定状态，本地全局配置不能覆盖服务器。同步数据与本地配置分别保存；退出远程服务器、再打开单人存档会清理同步缓存。
- 仅包含现有世界设置。个人哈气音量、物品显示角度、个人附近刷猫偏好仍保留在客户端配置中；航空箱独立产气不受猫咪哈气开关影响。

默认模板：`docs/config/laowu-global.toml`，数值项均为 -1，词条列表为 [-1]。示例（仅强制生命倍率与两个行为开关）：

```toml
show_hell_recipes = -1
wild_cats_flee = 0
cats_hiss = 0

[attribute_multipliers]
attack = -1
health = 2
speed = -1
stamina = -1
intelligence = -1
luck = -1
```

**文件修改与热重载：** 加载器重载 COMMON 文件后，新值在后续逻辑中生效；最多约 1 秒同步到在线玩家，界面锁定状态同时更新，旧草稿会失效。测试覆盖重新载入配置后的行为；未假定所有整合包都能可靠触发文件监控。最稳妥的操作是退出游戏/停服后修改，再启动。首次更新模组包也需要重启。

**验证：** `tests/run-global-world-config.ps1` 使用双端真实配置规格与 Minecraft NBT，覆盖六项属性、七项套装系数、整数/小数/-1、999999 边界、非法值纠正、存档切换、解除覆盖、锁定状态导致旧草稿版本变化、伪造锁定标记不能修改受保护字段、远程权威、断开连接清理、伤害溢出保护，以及默认 TOML 示例解析。仅替换无窗口测试所需的 FML 环境标记，未替换配置实现；完整游戏 UI 和联机流程仍需实例内验证。

## 生效时间

- 属性倍率：修改不重写任何猫咪的基础属性/上限/NBT。已加载猫咪的能力修饰符最迟约 20 tick（正常 TPS 下 1 秒）重算；最大生命变化保留当前生命比例，不凭空回满血。
- 后续攻击/钓鱼结算使用新倍率；正在执行的攻击冷却或已经发出的弹幕不倒计时重置、不追溯重算。
- 套装伤害系数：已加载猫咪在下一次服务端实体 tick 更新原有攻击属性修饰符，不重置生命、目标或冷却。近战、喷火、弹幕、自爆和荆棘反伤都复用这个攻击属性，不再额外乘配置。已发出的弹幕保留发射时的伤害。
- 野猫逃跑开关：下次 AI 检查生效；关闭时停止正在执行的原版逃跑导航。恢复开关后原版目标仍在，无需重新生成猫咪。
- JEI：设置同步后隐藏/恢复相应页；未安装 JEI 不影响游戏。不是配方禁用开关。
- GUI 保存后同步在线玩家，后来加入者同样收到配置；无需重进世界。
- 直接改文件：加载器重新载入配置后也会更新（每秒检查变更并同步）。最稳妥方式是先退出世界/停服，再编辑文件，重新进入/启动；不能只让联机客户端重进来代替服务端重载。不要在 GUI 和外部编辑器同时改文件。

## 属性倍率含义

六项分别设置 0～999999，默认 1。对公式输入 E 先乘对应倍率 M；固定项和套装固定生命/护甲/韧性加成不乘倍率。0 表示取消该属性的数值贡献，不表示生物生命/速度完全归零。鼠标悬停在对应倍率输入框可直接查看公式。

E 是现有计算好的当前属性（包含词条、条件、职业属性加成）。倍率不会改变属性面板中的 E、培养上限、繁育继承、父母筛选分数、训练进度、词条等级，也不修改智力 AI 分档和繁育幸运加成。

| 换算结果 | 公式 | E=0 | E=50 | E=100 | E=150 |
| --- | --- | ---: | ---: | ---: | ---: |
| 基础最大生命 | 10 + 0.4 × E × 生命倍率 | 10 | 30 | 50 | 70 |
| 职业伤害基数 | 2 + 0.08 × E × 战斗力倍率 | 2 | 6 | 10 | 14 |
| 基础护甲 | 2 + 0.16 × E × 耐力倍率 | 2 | 10 | 18 | 26 |
| 基础韧性 | 0.05 × E × 耐力倍率 | 0 | 2.5 | 5 | 7.5 |
| 移动倍率 | 0.75 + 0.005 × E × 速度倍率 | 0.75× | 1× | 1.25× | 1.5× |
| 暴击伤害倍率 | 1 + 0.01 × E × 智力倍率 | 1× | 1.5× | 2× | 2.5× |
| 暴击概率 | 2% + 0.18% × E × 幸运倍率 | 2% | 11% | 20% | 29% |
| 钓鱼战利品幸运 | 3 × E × 幸运倍率 / 100 | 0 | 1.5 | 3 | 4.5 |

表中 M=1；GUI 选中某个倍率输入框，会按草稿值更新这四档示例。概率上限 100%，钓鱼战利品幸运上限 5；Minecraft 自身的属性上限仍然有效。例如生命倍率 2 时，E=0/50/100/150 的基础最大生命为 10/50/90/130，不是把整个最大生命翻倍。

职业伤害乘下面可配置的套装伤害系数 K；无套装猫咪仍然不把战斗力换算成生物攻击伤害，物流猫咪不攻击。套装 Shift 实际数值预览和属性悬浮说明使用同一套换算函数。

职业攻击间隔：round(该职业基础间隔 - 该职业速度系数 × E × 速度倍率)，继续保留各职业最低间隔，最高 60 tick。不统一成所有职业相同的攻速。

## 套装伤害公式系数 K（纠正上一版含义）

V → 世界设置 → 套装伤害系数。这里直接修改各职业原公式中的 K，已经移除上一版“保留原系数后再乘一个倍率”的实现。

`攻击伤害 = (2 + 0.08 × 当前战斗力属性 × 战斗力倍率) × K`

这是生物攻击属性的基础计算，仍受 Minecraft 原生攻击属性上限限制。词条/药水等其他修饰、暴击、距离衰减、目标护甲和抗性按原逻辑处理。K 不再在命中事件、弹幕、自爆或荆棘反伤中重复相乘。

| 套装 | 配置键 | 存档默认 K |
| --- | --- | ---: |
| 机械猫咪 | terminator | 0.75 |
| 钓鱼猫咪 | fishing | 0.55 |
| 飞行员猫咪 | flight | 2 |
| 喷火猫咪 | fire | 0.6 |
| 采蜜猫咪 | honey | 0.85 |
| 物流猫咪 | transport | 0 |
| 雷管猫咪 | dynamite | 1.35 |

全局和存档 TOML 会在每一项上方自动生成中文套装名称与原始默认 K 的注释，默认值直接来自同一份套装定义。全局项额外注明 -1 沿用存档，不会为了展示默认值而把 -1 改成强制覆盖值；加载器更新配置时会保留这些正式注册的注释。

例如当前战斗力属性 100、战斗力倍率 1，机械猫默认 K=0.75，基础攻击伤害是 7.5；直接把 K 改为 1.2 后是 12，不是再乘原来的 0.75 得到 9。数值均不含暴击和目标减伤。套装 Shift 的“基础属性 100”预览另计套装自带战斗力属性 +10，所以对应预览是 8.1 / 12.96。

K 范围 0～999999，支持小数；0 使公式基础伤害为 0，1 表示 100% 的伤害基数，不代表恢复原职业默认值。它不改攻速、固定生命/护甲/韧性、属性加成、AI 和辅助效果。物流猫仍不主动攻击。雷管自爆仍为自身攻击属性的 5 倍，荆棘仍按自身攻击属性的既定比例计算；不对持续燃烧伤害添加整体倍率。

GUI 保留基础属性 0 / 50 / 100 / 150 示例，使用已生效的属性倍率和当前套装系数草稿。套装 Ctrl 的公式动态显示当前 K，Shift 和猫咪属性悬停预览复用相同公式。切换分页不丢失草稿。

套装页现升级为「套装配置」，按职业切换，并分为「战斗与防护」「属性加成」。其中「恢复默认」只恢复当前选中套装两组中所有可编辑参数，再点击「保存」生效。全局 TOML 锁定的项目、其他套装、六维属性倍率、行为开关、词条禁用设置保持不变；不会自动保存或改写全局文件。详见 [逐套装配置](suit-settings.md)。

全局配置示例（仅固定机械猫 K=1.2）：

```toml
[career_damage_coefficients]
terminator = 1.2
fishing = -1
flight = -1
fire = -1
honey = -1
transport = -1
dynamite = -1
```

全局 -1 使用存档，其他值直接固定 K 并锁定 GUI 对应项目。改回 -1 恢复存档原值。新分组名为 `career_damage_coefficients`，不再读取上一版含义错误的 `career_damage_multipliers`，避免旧的默认 1 被误当成所有职业的 K；缺少新分组时按表中原值生成。六项属性倍率、行为开关及存档其他设置保持不变。如手动设置过旧分组，请在新分组按目标 K 重新填写。

数值校验继续拒绝越界值、负数（全局 -1 除外）、NaN 和无穷大。999999 上限仅放宽配置，不改变猫咪基因或培养上限，也不移除原版生物属性上限、攻击间隔下限、暴击率上限。高伤害不会绕过原版攻击属性限幅。

回归：`tests/run-global-world-config.ps1` 覆盖双端真实配置规格、原职业默认系数、全局锁定、存档与远程隔离，并使用原版 AttributeInstance 检查 K=0.75/1.2/0/999999 的一次乘算及原版限幅；`node tests/career-damage-wiring.mjs` 检查原修饰符被更新、无第二次乘算、描述及 GUI 一致性。测试不代替实际游戏内战斗和视觉检查。

## 词条禁用

世界配置新增根级 `disabled_traits = []`；全局配置默认 `disabled_traits = [-1]` 跟随存档。填写固定词条 ID 数组可禁止其新生成、注液、繁育继承/突变和调整棒新增，不删除已有猫咪/猫饼的词条。两份 TOML 自动附上完整中文 ID 对照，世界 GUI 新增可搜索的词条禁用页。全局强制值锁定世界界面，解除覆盖后恢复存档原值。

见 [完整规则和旧数据保护](trait-blacklist-config.md)。

## 地狱配方展示

`show_hell_recipes = false`（默认隐藏）。

开启后显示：
- `laowu:liquid_cat_mixing`（搅拌）；
- `laowu:cat_powder_crushing`（粉碎）；
- `laowu:cat_powder_milling`（研磨，以及 Create 对应粉碎镜像）；
- `laowu:cat_strip_cutting`（锯切）。

配方本身始终可制作。猫饼非橘猫示例去重依旧保留，不会因此显示成百上千个材质配方。

## 野生猫咪逃跑

`wild_cats_flee = false`（新旧世界首次生成本配置均默认不逃跑）。

控制原版 AvoidEntityGoal 和 PanicGoal，只针对未驯养猫咪。宠物跟随/坐下/战斗及已有宠物不恐慌逻辑不变；不关闭“代码冲突”等词条的特殊行为，也不禁止随机走动。

开启时逃跑导航优先于普通猫咪配对哈气，不再被哈气吸附和位置锁覆盖。原版不躲避创造/旁观模式玩家，测试避人请使用生存模式；无可达逃跑路径、坐在坐垫或正在被查看的猫也不会强行移动。

## 猫咪哈气

`cats_hiss = true`（默认开启）。关闭时清理已加载猫咪的哈气姿势、吸附锁定及配对音效，并禁止普通配对、严选耄耋词条和物流猫再次进入哈气状态。哈气产出随之停止；物流包裹运输、无关战斗和黄油猫 Boss 的攻击提示音不受影响。

该项同样由管理员/单人世界主人修改、存档保存及同步。关闭时不扫描周围猫咪；逐个猫咪在下一次服务端 tick 清理状态。重新开启后正常重新寻找哈气对象。

## 配置界面与 Modern UI

世界设置和 V 键设置界面保留背景模糊，但每帧只绘制一次背景。1.21.1 的 Screen.render 自带 renderBackground，不能在画完标题后再调用它，否则会对已绘制文字进行第二次背景处理；1.20.1 的父类没有这个行为。

两个版本统一先提交背景绘制，再恢复白色、不透明的前景颜色和默认混合状态，在单独前景层绘制文字与控件。结束时提交前景缓存并恢复绘制状态。标题/提示/示例文字使用完整 ARGB 色值；不更改 Modern UI 配置、字体、布局或用户黑名单，也不引入 Modern UI 硬依赖。

需重启游戏加载更新包。构建检查不能替代游戏内视觉检查：验证开启 Modern UI 背景模糊时的 V 键界面和世界设置，以及输入框、按钮和悬停提示；关闭模糊或不安装 Modern UI 时同样应正常显示。
