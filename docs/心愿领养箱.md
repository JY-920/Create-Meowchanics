# 心愿领养箱

内部构建 accessories.35；Forge 1.20.1 / NeoForge 1.21.1。新方块 ID：`laowu:wish_adoption_box`，普通领养箱的原有领养机制不变。

## 使用

- 左上纸条显示当前一单的 NOW（当前基础六维属性）或 MAX（六维属性上限）。NOW 不计词条、套装、饰品与临时加成；判断口径在纸条悬停提示中说明。
- 按饰品原版稀有度固定要求数量：普通 2 项、稀有 3 项、史诗 4 项。每单随机选择互不重复的属性；可以是 ≥、≤ 或双边区间，边界数值算满足，所有条件必须同时满足。
- 把猫饼放入左下 9 格，满足后最迟下一个服务端刻（约 0.05 秒）完成领养。每只猫饼换取一件饰品，猫饼及其携带物品一并被领养，请先取走需要保留的装备和库存。
- 右上小格只是当前奖励预览，不能取出；奖励进入右下 9 格，可点击、Shift 转移或通过漏斗提取。产物格放不下时保留原猫饼、原交易条件和原奖励。
- 每次成功交易都会刷新条件与奖励。点击“锁定交易”后保留这一单，可反复使用；再次点击“已锁定”解锁，不会立即刷新，只影响之后的交易。
- 范围条件只比较属性，不额外要求成年、职业或无主。无需普通领养箱的等待时间，也无需村民。
- 制作取出成品时生成奖励与条件，并附在箱子物品上；物品说明可查看 NOW / MAX、具体条件和锁定状态，立牌也显示对应饰品图标。工作台普通取出、Shift 批量合成、机械动力自动合成都支持；NeoForge 还支持原版合成器。
- 条件、奖励、锁定与实际库存随世界保存。挖下来的箱子保留当时的交易卡和锁定状态，再放置不刷新；箱内实际库存单独掉落，不会复制到箱子物品，也不会掉出预览饰品。只有未锁定的成功交易才按原规则刷新下一单。
- 更新前没有交易信息的箱子物品会在服务端首次进入背包或放置时初始化；旧方块挖下时也会带走交易信息。

默认领养奖励池 35 件（普通 11、稀有 12、史诗 12），包含爆珠奶茶，不包含 Boss 专属黄油块。每件等概率，无锁定时相邻两单的奖励不同。黄油块保留史诗品质，只由黄油猫 Boss 掉落。通过 `laowu:boss_accessories` 物品标签登记的其他 Boss 专属饰品也会排除；黄油块额外有固定 ID 保护。有效数据包新增饰品仍可纳入普通奖励池。

旧箱子的合法奖励会保留，条件数量按新的档位调整；锁着黄油块等已禁用奖励的旧箱子会重抽合法交易，保留锁定状态和两侧库存。未要求的属性只是无要求，不代表属性必须低于某值。

## 合成

工作台：中心普通领养箱，上方纸，左右各一颗绿宝石，下方机械动力纸板（其余留空）。配方 ID 不变；使用保留原版有序配方行为的 `laowu:wish_adoption_box` 序列化器，客户端与服务端需同时更新。合成预览不抽取交易，实际取出时绑定。

## 饰品获取与猫袋

36 件饰品均取消合成配方；普通游戏中只保留心愿领养箱和对应 Boss 掉落。旧配方源文本归档在 `art/retired-accessory-recipes/accessories31.json`，不打入游戏包。已有饰品不会删除。

猫袋 `laowu:cat_pouch` 配方改为：顶行中间线，中行三张皮革，底行中间机械动力黄铜锭。右键普通猫或已趴平的活体猫饼猫，可直接保存为猫饼收进袋子，无需纸棍或铲子。容量仍为 128，在物品栏内右键装入／取出不变。

收纳保留原主人、基础属性与上限、词条、基因、套装、当前血量及全部装备／背包；不会触发死亡扣属性。猫咪被查看、骑乘使用、处于雷管临终状态或袋子已满时不收走；拒绝旁观者、隔墙和远距操作。此功能不扩大猫咪本身的 9 格物品栏。

## 实现保障

交易、随机、锁定都由服务器决定；客户端只显示菜单数据并发送原版容器按钮操作。输入、产物和奖励预览分离。多个玩家共享同一实际库存，锁定操作幂等，并验证当前菜单、距离、旁观者和原方块实体身份。

方块展示同步仅发送交易卡与锁定元数据，不向附近玩家广播猫饼内嵌的大量物品数据。合成、战利品表、物品模型、屏幕和渲染器分别按两端版本 API 注册；未增加 Mixin。
