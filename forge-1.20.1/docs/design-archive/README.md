# 猫咪扫描器设计归档

## `cat-scanner-horizontal-v1.zip`

- 布局：横版扫描器，仅显示六维属性。
- 属性内容直接合成到扫描器屏幕材质，不使用悬浮背景平面。
- 归档时间：2026-08-21。
- SHA-256：`A0FFB0CF642E01A975F1557BF85DAEC32B81DA5CE99507672D29067334B1E6EA`

压缩包保存了当时的扫描器渲染器、动态屏幕合成器、Blockbench 模型、物品模型、两张机身贴图，以及用户调好的物品栏/手持 K 键参数，可独立恢复该版设计。

现行开发版在此基础上采用竖版屏幕：六维属性位于上方，最多四个词条位于下方；机身使用 Alpha 混合渲染以保留模型中间玻璃的半透明效果。
